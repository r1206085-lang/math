## 一、 國中課綱對齊與完整三年級課程目錄（共 20 核心單元）

所有國中教材內容、學習目標與指標編碼必須嚴格對應**教育部十二年國民基本教育課程綱要—國民中小學暨普通型高級中等學校【數學領域】（第四學習階段：國中七至九年級）**，涵蓋**數與量、代數、幾何、統計與機率**四大核心主題，並完整編成以下 20 個核心教學單元：

### 【七年級（國一）階段】—— 奠定數系擴展與代數基礎（共 7 單元）
1. **數與數線**（`junior/lessons/grade7-01-integers.html`）：正負數與數線、絕對值的意義與幾何意義（`n-IV-2`, `N-7-1 ~ N-7-5`）。
2. **整數的運算**（`junior/lessons/grade7-02-integer-operations.html`）：整數的加減乘除與四則混合運算、指數律（`n-IV-2`, `N-7-3 ~ N-7-4`, `N-7-8`）。
3. **分數的運算**（`junior/lessons/grade7-03-fractions.html`）：分數的加減乘除、科學記號（`n-IV-1`, `n-IV-3`, `N-7-6 ~ N-7-8`）。
4. **代數式與一元一次方程式**（`junior/lessons/grade7-04-linear-equations.html` / `grade7-02-linear-equations.html`）：列代數式、化簡、等量公理與一元一次方程式應用問題（`a-IV-1`, `a-IV-2`, `A-7-1 ~ A-7-3`）。
5. **二元一次聯立方程式**（`junior/lessons/grade7-05-simultaneous-equations.html`）：二元一次方程式的意義、代入消去法、加減消去法與應用題（`a-IV-4`, `A-7-4 ~ A-7-5`）。
6. **直角座標系與二元一次方程式的圖形**（`junior/lessons/grade7-06-coordinates.html`）：座標平面、象限、線性函數圖形（`g-IV-1`, `a-IV-4`, `G-7-1`, `A-7-6`）。
7. **比與比例式**（`junior/lessons/grade7-07-ratios.html`）：比例的意義、連比例、正比與反比（`n-IV-4`, `n-IV-9`, `N-7-9`）。

### 【八年級（國二）階段】—— 進入多項式、根號與幾何推理（共 8 單元）
1. **乘法公式與多項式**（`junior/lessons/grade8-01-polynomials.html`）：和的平方、差的平方、平方差公式；多項式的加減乘除直式運算（`a-IV-5`, `A-8-1 ~ A-8-3`）。
2. **平方根與根號運算**（`junior/lessons/grade8-02-square-roots.html`）：根號的意義、最簡根號、近似值與根號的四則運算（`n-IV-5`, `n-IV-6`, `N-8-1 ~ N-8-2`）。
3. **勾股定理（畢氏定理）**（`junior/lessons/grade8-03-pythagorean.html` / `grade8-01-pythagorean.html`）：直角三角形三邊長關係 $a^2 + b^2 = c^2$、斜邊上的高（`s-IV-7`, `S-8-6`）。
4. **因式分解**（`junior/lessons/grade8-04-factorization.html` / `grade8-02-factorization.html`）：提公因式法、乘法公式因式分解、十字交乘法（`a-IV-5`, `A-8-4 ~ A-8-5`）。
5. **一元二次方程式**（`junior/lessons/grade8-05-quadratic-equations.html`）：因式分解法解一元二次方程式、配方法、公式解與應用問題（`a-IV-6`, `A-8-6 ~ A-8-7`）。
6. **數列與級數**（`junior/lessons/grade8-06-sequences.html`）：等差數列、等差級數、等比數列（`n-IV-7`, `n-IV-8`, `N-8-3 ~ N-8-4`, `N-9-1`）。
7. **幾何證明與三角形的心**（`junior/lessons/grade8-07-triangle-centers.html`）：外心、內心、重心性質與幾何推論（`s-IV-9`, `s-IV-11`, `s-IV-12`, `S-8-7 ~ S-8-8`, `S-9-8 ~ S-9-11`）。
8. **平行與四邊形**（`junior/lessons/grade8-08-quadrilaterals.html`）：平行線的性質、平行四邊形、矩形、菱形、箏形與梯形（`s-IV-8`, `S-8-9 ~ S-8-11`）。

### 【九年級（國三）階段】—— 挑戰函數、相似形與統計機率（共 5 單元）
1. **相似形**（`junior/lessons/grade9-01-similarity.html`）：比例線段、三角形相似性質（$AA$、$SAS$、$SSS$）、相似形面積與體積比（`s-IV-10`, `S-9-1 ~ S-9-4`）。
2. **點、直線與圓的關係**（`junior/lessons/grade9-02-circles.html`）：圓心角與圓周角、弦心距、切線性質、內切圓與外接圓（`s-IV-14`, `S-9-5 ~ S-9-7`）。
3. **二次函數**（`junior/lessons/grade9-03-quadratic-functions.html`）：二次函數的圖形（頂點、對稱軸、開口方向）、最大值與最小值應用（`f-IV-2`, `F-9-1 ~ F-9-2`）。
4. **統計與機率**（`junior/lessons/grade9-04-statistics-probability.html`）：次數分配直方圖、折線圖、累積次數分配、平均數、中位數、眾數、四分位數與古典機率（`d-IV-1`, `d-IV-2`, `D-7-1 ~ D-7-2`, `D-9-1 ~ D-9-3`）。
5. **生活中的立體圖形**（`junior/lessons/grade9-05-3d-geometry.html`）：角柱、圓柱、錐體與球體的表面積與體積計算（`s-IV-15`, `s-IV-16`, `S-7-2`, `S-9-12 ~ S-9-13`）。

## 二、 高中課綱對齊與完整三年級課程目錄（`high/` 專區）

高中專區教材（`high/core-lessons/`）與三年個人手寫錯題本（`high/my-mistakes/`）必須嚴格對應普通高級中學必修與選修數學課程綱要（並嚴守課綱備註欄「避免無意義人工化難題」之規範）：

### 【高一（十年級）階段】—— 對應錯題本：`high/my-mistakes/grade10-algebra.html`
- **高一上（數學 I：函數與連續量）**
  1. **數與式**：有理數與循環小數、實數十進位表示、雙重根式化簡、算幾不等式 $\sqrt{ab} \le \frac{a+b}{2}$、乘法公式（含立方和與差）、分點公式、含絕對值的一次方程式與不等式（*備註：不含雙十字交乘法與 $x^3+y^3+z^3-3xyz$*）。
  2. **多項式函數**：一次函數斜率（變化率）、二次函數配方法與**正定性（恆正性）**、單項函數 $y=cx^n(n\le 4)$ 奇偶性與平移、綜合除法、餘式與因式定理、連續綜合除法求 $(x-a)$ 冪方展開近似值、**牛頓與拉格朗日插值多項式（不超過三次）**、二次方程式複數根、有理根判定法與**勘根定理**、實係數代數基本定理與**虛根成對定理**、已分解多項式圖形與簡易分式不等式（*備註：不含複雜分式不等式、不含最高公因式*）。
  3. **指數與對數函數**：整數／分數／實數指數律、指數函數（$2^x, 10^x$）與對數函數（$\log x$）之圖形、單調性與**凹凸性（連結算幾不等式）**、對數定義與三大對數定律、**換底公式（以換成 $10$ 為底 $\log_a x = \frac{\log x}{\log a}$ 為主）**、對數表（**內插法**）、科學記號與乘除次方估計、等比數列與級數、生活模型應用（*備註：刪除衍生怪公式與表尾差，純人工化指對數方程／不等式不宜過度延伸*）。
  4. **附錄**：命題、充分／必要／充要條件、反證法（含 $\sqrt{2}$ 為無理數的證明）。
- **高一下（數學 II：有限數學與離散量）**
  5. **數列與級數**：發現數列規律（一階遞迴關係）、**數學歸納法**、$\Sigma$ 符號與基本求和公式 $\sum k, \sum k^2, \sum \frac{1}{k(k+1)}$（*備註：不含二階遞迴*）。
  6. **排列、組合**：邏輯與笛摩根定律、集合與文氏圖、窮舉法與樹狀圖、**一一對應原理**、加法與乘法原理、**取捨原理（PIE，至多三集合）**、球與籃子模型（直線排列 $P^n_k$、重複排列 $n^k$、組合 $C^n_k$、重複組合 $C^{n+k-1}_k$）、**二項式定理與巴斯卡三角形**（*備註：不含環狀排列、不含超過二項的展開式*）。
  7. **機率**：樣本空間與事件、古典機率、**條件機率與貝氏定理**、獨立事件（*備註：不含幾何機率*）。
  8. **數據分析**：一維數據（平均數 $\mu$、標準差 $\sigma$、**數據標準化** $z_i=\frac{x_i-\mu}{\sigma}$）、二維數據（散佈圖、無因次標準化導出**相關係數 $r$ 與最小平方法迴歸直線** $\hat{y}=r\hat{x}$）；附錄含輾轉相除法与二分逼近法。

### 【高二（十一年級）階段】—— 對應錯題本：`high/my-mistakes/grade11-trig.html`
- **高二上（數學 III：平面坐標與向量）**
  1. **三角**：直角三角形邊角關係（$\sin, \cos, \tan$）、廣義角與極坐標（引進**參考角 $\alpha$** 與單位圓補角關係）、**正弦定理與餘弦定理（幾何分割與坐標幾何雙證法）**、海龍公式、由餘弦定理證明**差角公式 $\cos(\theta_2-\theta_1)$** 及和角／倍角／半角公式、平面與立體三角測量（*備註：不含和差化積與積化和差*）。
  2. **直線與圓**：點斜式、兩線平行與垂直、聯立方程式幾何意涵、二元一次不等式與**線性規劃（目標函數為一次式）**、圓的方程式、圓與直線相切／相割／不相交的代數與幾何判定（*備註：不含兩圓的關係*）。
  3. **平面向量**：幾何與坐標表示、線性組合、分點公式、重心與內心、直線參數式、**內積與餘弦定理關聯**、正射影、向量直交化、**柯西不等式**、法向量與點線距、**面積與二階行列式**、二階克拉瑪公式。
- **高二下（數學 IV：空間向量與線性代數，◎為 B 版增加）**
  4. **空間向量**：空間概念、空間坐標與距離公式、空間向量線性組合與內積、**外積 $\vec{a}\times\vec{b}$ 與平行四邊形面積**、平行六面體體積與 **◎三階行列式定義與性質**（*備註：不含特殊技巧之行列式題型*）。
  5. **空間中的平面與直線**：平面法向量、兩平面夾角、點到平面距離、空間直線參數式與比例式、線面關係、**◎點線距／平行線距／兩歪斜線距離**、三元一次聯立方程組消去法與 **◎三平面幾何關係代數判定**。
  6. **矩陣**：高斯消去法（矩陣列運算三角化）、矩陣加乘運算、**轉移矩陣**、二階反方陣、**◎平面上的線性變換（伸縮、旋轉、鏡射、推移）與面積比 $|\det A|$**（*備註：不談特徵方程式及 Cayley-Hamilton 定理*）。

### 【高三（十二年級）階段】—— 對應錯題本：`high/my-mistakes/grade12-calculus.html`
- **高三上（選修數學甲 I／數學乙 I）**
  1. **機率統計 II**：離散隨機變數、機率質量函數、期望值、變異數與標準差、獨立重複試驗與**二項分布**、簡單隨機抽樣、亂數表、**常態分布與信賴區間及信心水準解讀**（*備註：不含系統抽樣、部落抽樣*）。
  2. **三角函數**：弧度（弳）、扇形弧長與面積、六種三角函數（含 $\cot, \sec, \csc$）圖形與週期、簡諧波動與**同週期正餘弦函數的疊合** $A\sin(\omega t+\theta_0)$、圓與橢圓的參數式、**複數平面与極式、棣美弗定理、複數的 $n$ 次方根**（*備註：不含不同週期的三角函數疊合、不做單位根變形的複雜級數*）。
- **高三下（選修數學甲 II／數學乙 II）**
  3. **極限與函數**：不等式型數學歸納法、數列極限、**無窮等比級數**、循環小數化分數證明、**夾擠定理（內接外切正 $n$ 邊形逼近圓面積）**、合成函數、函數極限、連續函數與**介值定理**。
  4. **二次曲線（圓錐曲線）**：
     - **拋物線**：焦點、準線、頂點、對稱軸與標準式 $\sqrt{x^2+(y-c)^2}=|y+c|$ 及平移伸縮。
     - **橢圓**：兩焦點距離和 $2a$、中心、長短軸與標準式 $\frac{(x-h)^2}{a^2}+\frac{(y-k)^2}{b^2}=1$ 及平移伸縮。
     - **雙曲線**：兩焦點距離差 $2a$、貫軸、共軛軸、漸近線、共軛雙曲線與標準式及平移伸縮（*備註：不含傾斜或退化的二次曲線、不含直線與二次曲線的弦與切線關係、不含光學性質*）。
  5. **多項式函數的微積分**：導數定義與切線、微分加减乘運算、一階與二階導數檢定法（遞增遞減、極值、凹凸性、反曲點）與**三次多項式函數繪圖**、定積分上下和極限、**微積分基本定理**、多項式積分求**圓面積、球體體積 $\frac{4}{3}\pi R^3$、角錐體體積 $\frac{1}{3}AH$** 與自由落體運動；附錄含牛頓求根法（*備註：不涉及分部積分與變數變換法*）。

## 三、 單元頁面五大核心區塊規範

每一個核心單元頁面（`junior/lessons/*.html` 與 `high/core-lessons/*.html`）及錯題本頁面（`high/my-mistakes/*.html`）**必須完整包含以下五大標準區塊**，缺一不可：

1. **頂部導覽列（Top Navigation）**
   - 包含返回總首頁（`index.html`）與專區首頁按鈕、當前所屬年級與單元標章、核心主題分類標籤，以及快速跳轉本頁各區塊的錨點與上下單元導覽。
2. **標題與學習目標區塊（Title & Learning Objectives）**
   - 明確標示單元名稱、課綱對應之主題與子題條目（含備註欄評量邊界），並條列具體的學生學習目標。
3. **💡 生活化比喻與情境引言（Real-life Analogy）**
   - 將抽象數學概念轉化為學生熟悉的生活情境，搭配視覺化圖解或結構化示意卡片。
4. **📘 核心公式表格與常見錯誤觀念提醒（Core Formula Table & Common Pitfalls）**
   - 使用結構化 HTML `<table>` 清楚整理本單元必背定義、公式、適用條件與推導關鍵（搭配 MathJax 公式）。
   - 附上醒目的「⚠️ 常見易錯觀念提醒（正誤對照表）」，直接點破學生最常犯的計算或觀念陷阱；高中頁面並須串聯至 `high/my-mistakes/` 對應年級的個人手寫錯題本。
5. **✍️ 經典題型／個人錯題與折疊詳解（Classic Problems & Personal Mistakes with `<details>` Solutions）**
   - 核心講義提供至少 3 道由淺入深的課綱代表例題；個人錯題本（`high/my-mistakes/`）則完整收錄使用者提供的實戰錯題與 AI 診斷。
   - **強制規定**：每題下方必須包含「🧠 解題破題思路」並使用原生 HTML `<details>` 與 `<summary>` 標籤實作「點擊展開逐步詳解」，讓學生先思考再看解答。

## 四、 🔄 專案自動化 Loop / Graph 檢核機制

本專案為確保生成的數學科普與三年高中錯題本品質，在 AI Agent 的執行流程中導入了嚴格的 **Self-Correction Loop（自我修正迴圈）**：

```mermaid
graph TD
    A[開始：接收錯題與單元資料] --> B[Phase 1: 依照單元結構生成 HTML 頁面]
    B --> C{Phase 2: 自我檢核 (Self-Check)}
    C -->|MathJax 語法錯誤 / 內容有省略 / 缺少單元| D[自動觸發 Retry 迴圈]
    D --> B
    C -->|檢查合格，結構完整| E[Phase 3: 自動更新高低年級專區索引]
    E --> F[同步更新總首頁 index.html 連結]
    F --> G[完成部署並輸出成果]
```

### 自動化檢核三階段執行細則：
1. **Phase 1（依照單元結構生成 HTML 頁面）**：
   - 嚴格依據本手冊「五大核心區塊」與課綱範圍生成 HTML，絕不使用 `<!-- 其餘省略 -->` 或半成品佔位符。
   - 使用者提供的所有個人錯題與詳解，必須嚴格歸類至 `high/my-mistakes/` 底下對應年級（`grade10-algebra.html`、`grade11-trig.html`、`grade12-calculus.html`）的單元頁面中。
2. **Phase 2（自我檢核 Self-Check 與自動 Retry 迴圈）**：
   - 每次生成或更新 HTML 檔案後，AI Agent 必須自動檢查：
     - **MathJax 語法**：檢查 `$ ... $` 與 `$$ ... $$` 成對閉合、`\frac{}{}`、`\sqrt{}`、`\begin{cases}...\end{cases}` 等 LaTeX 大括號無缺漏。
     - **HTML 結構與內容完整性**：確認五大區塊、`<details>` 與 `<summary>` 折疊詳解完整無省略，且未違反課綱備註欄禁令。
     - **單元與連結完整性**：檢查所有相對路徑（`../`、`../../`）目標檔案皆實際存在。
   - 若發現任何語法錯誤、內容省略或缺少單元，**立即自動觸發 Retry 迴圈退回 Phase 1 重新修正**，直到 100% 檢查合格。
3. **Phase 3（自動同步專區索引與總首頁 `index.html`）**：
   - 檢查合格後，自動更新 `high/index.html`、`high/my-mistakes/index.html`、`junior/index.html`，並同步更新根目錄總首頁 `index.html`，確保全站雙入口與所有子頁面連結 100% 暢通、絕無 404 錯誤。
