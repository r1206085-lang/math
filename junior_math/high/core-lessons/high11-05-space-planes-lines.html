空間中的平面與直線：平面法向量、直線參數式與三元一次方程組

在三維空間中精準定位平面與直線！掌握「平面看唯一法向量 $\vec{n}$、直線看唯一方向向量 $\vec{v}$」的黃金準則，並學會判斷直線與平面關係、點面距與三平面相交的幾何意涵！

📌 課綱備註：◎2.2 點到直線距離、兩平行線距離、兩歪斜線距離及 ◎3.2 三平面幾何關係代數判定為 B 版增加題材。

🎯 課綱核心學習目標

  • ✓能由平面法向量 $\vec{n} = (a,b,c)$ 與一點寫出平面點法式，並求兩平面的夾角與點到平面的距離。
  • ✓熟練空間直線的參數式与對稱比例式，並能將直線參數式代入平面方程式判別線面關係（交於一點、平行不相交、直線在平面上）。
  • ✓（◎ B 版）能計算空間中點到直線距離、兩平行線距離與兩歪斜線公垂線段距離。
  • ✓熟練三元一次聯立方程組的消去法（求插值多項式、過三點之圓）與三平面幾何關係判定。

1. 生活情境引言：空間沒有「斜率」，改用法向量與方向向量導航！

為什麼在三維空間裡，$2x + y - z = 3$ 代表的不是一條直線，而是一整片平面？

🛸 情境一：平面只有「唯一法向量 $\vec{n}$」，直線只有「唯一方向向量 $\vec{v}$」

在三維空間中：垂直於一條直線的方向有無限多個（一整個圓盤），但垂直於一片平面的方向只有唯一一個（法向量 $\vec{n}$）！

  • 因此平面方程式用一個一次式 $a(x-x_0)+b(y-y_0)+c(z-z_0)=0$ 就能藉由 $\vec{n}\perp\vec{AP}$ 唯一鎖定！
  • 相反地，空間直線必須用參數式 $(x,y,z) = (x_0+at, y_0+bt, z_0+ct)$（起點＋方向向量 $\vec{v}$ 乘時間 $t$）來描述！

🎯 情境二：判別直線與平面關係 ＝ 把參數式 $(x(t), y(t), z(t))$ 直接代進平面！

課綱第 66 頁指定範例：如何判別直線 $L$ 與平面 $E$ 的關係？

  • 將直線上的動點參數式代入平面 $E$，解關於 $t$ 的一元一次方程式：
  • ① 若解出唯一一個 $t$ $\implies$ 直線與平面交於唯一一點；
    ② 若 $t$ 消掉變成矛盾式（如 $0t = 5$） $\implies$ 平行不相交；
    ③ 若變成恆等式 $0t = 0$ $\implies$ 整條直線躺在平面上！

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
平面方程式、夾角與點面距 • 點法式：$a(x-x_0) + b(y-y_0) + c(z-z_0) = 0$，法向量 $\vec{n} = (a,b,c)$
• 兩平面夾角 $\theta$：$\cos\theta = \pm\frac{\vec{n}_1\cdot\vec{n}_2}{|\vec{n}_1||\vec{n}_2|}$
• 點 $P(x_0,y_0,z_0)$ 到平面 $E: ax+by+cz+d=0$ 距離：$$d(P, E) = \frac{|ax_0 + by_0 + cz_0 + d|}{\sqrt{a^2 + b^2 + c^2}}$$		 • 兩平行平面 $ax+by+cz+d_1=0$ 與 $ax+by+cz+d_2=0$ 的距離為 $\frac{|d_1 - d_2|}{\sqrt{a^2+b^2+c^2}}$（須先將 $a,b,c$ 係數化為相同！）。
空間直線參數式與比例式 過點 $A(x_0,y_0,z_0)$、方向向量 $\vec{v}=(a,b,c)$：
• 參數式：$x = x_0 + at, \; y = y_0 + bt, \; z = z_0 + ct \quad (t \in \mathbb{R})$
• 對稱比例式：$\frac{x-x_0}{a} = \frac{y-y_0}{b} = \frac{z-z_0}{c} \quad (abc \neq 0)$		 • 比例式中分子的 $x, y, z$ 係數必須全部化為 $+1$，分母才是真正的方向向量 $(a,b,c)$！
空間點線距與兩歪斜線距離（◎） • 點 $P$ 到直線 $L$：將動點 $Q(t)$ 表為參數式，當 $\vec{PQ} \perp \vec{v} \iff \vec{PQ}\cdot\vec{v}=0$ 時即得投影點 $Q$ 與最短距離。
• 兩歪斜線 $L_1, L_2$ 距離：取公垂向量 $\vec{n} = \vec{v}_1 \times \vec{v}_2$，距離為 $|\vec{P_1P_2}|$ 在 $\vec{n}$ 上的正射影長 $\frac{|\vec{P_1P_2}\cdot\vec{n}|}{|\vec{n}|}$。		 • 判別兩直線是否為歪斜線：① 方向向量不平行 且 ② 聯立參數式無交點。

❌ 錯題盲點 1：對稱比例式未將分子 $x,y,z$ 係數化為 $+1$ 就直接讀方向向量

常見誤區：看到 $\frac{x-1}{2} = \frac{2-y}{3} = \frac{2z+4}{6}$，誤以為方向向量是 $(2, 3, 6)$。

✅ 正確課綱觀念：必須先改寫為 $\frac{x-1}{2} = \frac{y-2}{-3} = \frac{z+2}{3}$，故真正的方向向量為 $(2, -3, 3)$！

❌ 錯題盲點 2：在空間中求點到「直線」距離時，誤代點到「平面」的絕對值公式

常見誤區：想用 $\frac{|ax_0+by_0+cz_0+d|}{\sqrt{a^2+b^2+c^2}}$ 算點到直線距離。

✅ 正確課綱觀念：空間中一次式代表的是平面而非直線！算空間點到直線距離必須用「參數式動點 $\vec{PQ}\cdot\vec{v}=0$」或畢氏定理 $\sqrt{|\vec{AP}|^2 - \text{投影長}^2}$！

❌ 錯題盲點 3：兩平行平面距離公式忘記先統一法向量係數

常見誤區：求 $x + 2y - 2z + 1 = 0$ 與 $2x + 4y - 4z + 8 = 0$ 的距離直接算 $\frac{|1-8|}{3}$。

✅ 正確課綱觀念：必須先將第二式同除以 $2$ 化為 $x + 2y - 2z + 4 = 0$，距離才是 $\frac{|1 - 4|}{\sqrt{1^2+2^2+(-2)^2}} = \frac{3}{3} = \mathbf{1}$！

課綱指定範例 1 判別空間直線與平面的相交關係及交點

1. 試判別空間直線 $L: \frac{x - 1}{2} = y + 1 = \frac{z}{3}$ 與平面 $E: 2x + y - z = 3$ 的位置關係；若相交，並求出其交點坐標。

🧠 解題破題思路：令對稱比例式 $= t$，寫出參數式 $(x, y, z) = (1+2t, -1+t, 3t)$，代入平面 $E$ 解 $t$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：將直線 $L$ 化為參數式

令 $\frac{x-1}{2} = \frac{y+1}{1} = \frac{z}{3} = t$，得動點坐標為 $(1 + 2t, \; -1 + t, \; 3t), \; t \in \mathbb{R}$。

步驟 2：代入平面 $E: 2x + y - z = 3$

$$2(1 + 2t) + (-1 + t) - 3t = 3 \implies 2t + 1 = 3 \implies t = 1$$

因為 $t = 1$ 有唯一解，故直線 $L$ 與平面 $E$ 相交於唯一一點，代回 $t = 1$ 得交點為 $(3, 0, 3)$。

答：直線與平面相交於一點 $(3, 0, 3)$。

課綱核心範例 2 過不共線三點求平面方程式與點到平面距離

2. 已知空間中三點 $A(1, 1, 0), \; B(2, 3, 1), \; C(0, 2, 2)$。試求：
(1) 通過 $A, B, C$ 三點的平面 $E$ 方程式。
(2) 點 $P(3, -1, 4)$ 到平面 $E$ 的距離。

🧠 解題破題思路：平面法向量 $\vec{n}$ 同時垂直於 $\vec{AB}$ 與 $\vec{AC}$，故取外積 $\vec{n} = \vec{AB} \times \vec{AC}$ 即可直接寫出平面方程式！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：由外積求平面法向量 $\vec{n}$

$$\vec{AB} = (1, 2, 1), \quad \vec{AC} = (-1, 1, 2)$$

$$\vec{n} = \vec{AB} \times \vec{AC} = (3, -3, 3) = 3(1, -1, 1)$$

取最簡法向量 $(1, -1, 1)$，代入點 $A(1,1,0)$ 得平面 $E: x - y + z = 0$。

步驟 2：求點 $P(3, -1, 4)$ 到平面 $E$ 的距離

$$d(P, E) = \frac{|3 - (-1) + 4|}{\sqrt{1^2 + (-1)^2 + 1^2}} = \frac{8}{\sqrt{3}} = \frac{8\sqrt{3}}{3}$$

答：(1) $x - y + z = 0$；(2) $\frac{8\sqrt{3}}{3}$。

課綱核心範例 3（◎ B 版 p.66） 空間中點到直線的最短距離與投影點

3. 求空間中點 $P(2, 3, 1)$ 到直線 $L: \frac{x-1}{1} = \frac{y}{2} = \frac{z+1}{2}$ 的最短距離及投影點 $Q$ 的坐標。

🧠 解題破題思路：設投影點為參數式 $Q(1+t, 2t, -1+2t)$，利用 $\vec{PQ} \perp \vec{v}(1,2,2) \implies \vec{PQ}\cdot(1,2,2) = 0$ 解出 $t$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：設投影點 $Q(1+t, 2t, -1+2t)$ 並利用內積為 $0$ 求 $t$

$$\vec{PQ} = (t - 1, \; 2t - 3, \; 2t - 2)$$

因 $\vec{PQ} \perp \vec{v}(1, 2, 2)$：

$$1(t - 1) + 2(2t - 3) + 2(2t - 2) = 0 \implies 9t - 11 = 0 \quad \text{？若改取 } P(2, 4, 1)$$

對原點 $P(2,3,1)$：$9t = 11 \implies t = \frac{11}{9}$；若點為 $P(3, 2, 1)$，則 $\vec{PQ}=(t-2, 2t-2, 2t-2) \implies (t-2)+4t-4+4t-4=0 \implies 9t=10$。對本題 $P(2,3,1)$，$t = \frac{11}{9}$，故 $Q\left(\frac{20}{9}, \frac{22}{9}, \frac{13}{9}\right)$，$\vec{PQ} = \left(\frac{2}{9}, -\frac{5}{9}, \frac{4}{9}\right)$，距離 $|\vec{PQ}| = \frac{\sqrt{4+25+16}}{9} = \frac{\sqrt{45}}{9} = \frac{\sqrt{5}}{3}$！

答：投影點 $Q\left(\frac{20}{9}, \frac{22}{9}, \frac{13}{9}\right)$，最短距離為 $\frac{\sqrt{5}}{3}$。
