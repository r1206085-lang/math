高中核心單元 09 / 18 • 數學 III • 二、直線與圓 (1.1 ~ 3.2)

直線與圓：點斜式、平行垂直、線性規劃與圓切線關係

以「點斜式 $y - y_0 = m(x - x_0)$」為直線核心，掌握兩線平行與垂直斜率關係、二元一次不等式與線性規劃平行直線系，以及圓與直線相切、相割、不相交的代數與幾何雙判定！

📌 課綱備註：直線主要談點斜式，不要讓學生死背太多公式；線性規劃目標函數限為一次式；不含兩圓的關係。

🎯 課綱核心學習目標

  • ✓熟練直線的點斜式 $y - y_0 = m(x - x_0)$，並能推演過一點平行或垂直於給定直線的方程式（垂直時 $m_1m_2 = -1$）。
  • ✓理解二元一次聯立方程式的幾何意涵（相交恰一解、平行無解、重合無限多解），並能解決對稱點與光的反射問題。
  • ✓能在坐標平面標示二元一次不等式區域，並利用平行直線系 $ax + by = k$（或頂點法）解決一次目標函數的線性規劃問題。
  • ✓掌握圓的標準式 $(x-h)^2+(y-k)^2=r^2$ 與一般式，並能用代數判別式或圓心到直線距離 $d$ 與半徑 $r$ 判定圓與直線的關係。

1. 生活情境引言：光線鏡面反射與工廠最大利潤平行推尺法

課綱為什麼強調只要記熟「點斜式」就能打天下？判斷圓與直線相切用哪一招最快？

📐 情境一：點斜式就是「起點＋方向斜率」

課綱第 62 頁指出：不需死背兩點式、截距式等繁雜公式名稱，全部由點斜式推演即可：

  • 只要知道直線上一個點 $(x_0, y_0)$ 跟斜率 $m = \frac{\Delta y}{\Delta x}$，方程式立刻寫出 $y - y_0 = m(x - x_0)$！
  • 對於一般式 $ax + by + c = 0$，平行線直接設 $ax + by = k$；垂直線直接係數對調變號設 $bx - ay = k$，代點進去三秒鐘搞定！

⭕ 情境二：圓與直線關係——「幾何距離 $d$ vs. $r$」完勝代數硬展開！

雖然課綱介紹代入消去後的判別式 $D$（$D>0$ 相割、$D=0$ 相切、$D<0$ 不相交）：

  • 實戰時直接算圓心 $O(h,k)$ 到直線 $L$ 的距離 $d$ 與半徑 $r$ 比較（$d < r$ 相割、$d = r$ 相切、$d > r$ 不相交），計算量只有代數法的三分之一！
  • 看到弦長 $\overline{AB}$，立刻畫「圓心、弦中點、端點」構成的直角三角形：半弦長 $= \sqrt{r^2 - d^2}$！

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
直線點斜式與平行垂直條件 • 點斜式：$y - y_0 = m(x - x_0)$
• 兩線平行：$m_1 = m_2$（且不重合）
• 兩線垂直：$m_1 \cdot m_2 = -1$（或一鉛直一水平）		 • 過點 $P$ 關於直線 $L$ 的鏡射對稱點 $P'$：滿足 ① $\overline{PP'} \perp L$ 且 ② $\overline{PP'}$ 中點落在 $L$ 上。
二元一次不等式與線性規劃 設直線 $L: ax + by + c = 0 \; (a > 0)$：
• 右半平面：$ax + by + c > 0$
• 左半平面：$ax + by + c < 0$		 • 首項係數 $a > 0$ 時，「大於在右、小於在左」。
• 線性規劃一次目標函數 $f(x,y) = px + qy$ 的極值必發生在可行解區域的頂點（或邊界線段）上。
圓的標準式與一般式 • 標準式：$(x - h)^2 + (y - k)^2 = r^2$
• 一般式：$x^2 + y^2 + dx + ey + f = 0$
• 配方法得圓心 $\left(-\frac{d}{2}, -\frac{e}{2}\right)$，判別式 $d^2 + e^2 - 4f > 0$ 時為實圓		 • 若 $d^2+e^2-4f = 0$ 退化為一點；若 $< 0$ 則無圖形（虛圓）。
• 以 $A(x_1,y_1), B(x_2,y_2)$ 為直徑端點的圓：$(x-x_1)(x-x_2)+(y-y_1)(y-y_2)=0$。
圓與直線關係及切線公式 圓心到直線距離 $d = \frac{|ah + bk + c|}{\sqrt{a^2 + b^2}}$：
• $d < r \iff$ 相割於兩點（弦長 $= 2\sqrt{r^2 - d^2}$）
• $d = r \iff$ 相切於一點（判別式 $D = 0$）
• $d > r \iff$ 不相交		 • 過圓外一點 $(x_0, y_0)$ 求切線：設點斜式 $y - y_0 = m(x - x_0)$，利用 $d = r$ 解 $m$（必有兩條切線，若只解出一條 $m$，代表另一條為鉛直切線 $x = x_0$！）。

3. 常見易錯觀念提醒（課綱盲點診斷）

掃除觀念盲點後，點擊右側按鈕可進入「高中數學錯題本」查看實戰錯題

📓 進入本年級個人手寫錯題本 (grade11-trig.html) →

❌ 錯題盲點 1：過圓外一點求切線只解出一個斜率 $m$，漏掉鉛直切線

常見誤區：設 $y - y_0 = m(x - x_0)$ 代入 $d = r$ 平方後二次項消掉只得一解，就以為只有一條切線。

✅ 正確課綱觀念：過圓外一點必有兩條切線！當點斜式只算出一個 $m$ 時，代表另一條切線斜率不存在，務必補上鉛直線 $x = x_0$！

❌ 錯題盲點 2：看到 $x^2 + y^2 + dx + ey + f = 0$ 未先確認 $d^2 + e^2 - 4f > 0$

常見誤區：題目問「過點 $(1,2)$ 到圓 $x^2+y^2+2x-4y+k=0$ 的切線段長」，忘了實圓條件。

✅ 正確課綱觀念：必須先確保配方法後的半徑平方 $r^2 = \frac{d^2+e^2-4f}{4} > 0$，方程式才真正代表一個圓！

❌ 錯題盲點 3：二元一次不等式判斷左右半平面時未確認 $x$ 係數 $a > 0$

常見誤區：看到 $-2x + 3y - 6 > 0$ 就以為在直線右方。

✅ 正確課綱觀念：使用「大於在右、小於在左」口訣前，必須先將 $x$ 的係數化為正數（或直接代入原點 $(0,0)$ 測試最穩當）！

課綱指定範例 1 過直線外一點求平行與垂直直線及對稱點

1. 已知點 $P(1, 5)$ 與直線 $L: 2x - y + 3 = 0$。試求：
(1) 過點 $P$ 且與 $L$ 垂直的直線方程式。
(2) 點 $P$ 在直線 $L$ 上的投影點 $H$ 與鏡射對稱點 $P'$ 的坐標。

🧠 解題破題思路：與 $2x - y + 3 = 0$ 垂直的直線可設為 $x + 2y = k$，代入 $P(1,5)$ 得 $x + 2y = 11$；兩線解聯立即得投影點（垂足）$H$，再用中點公式 $P' = 2H - P$ 秒殺對稱點！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：求垂直線方程式

設與 $L: 2x - y + 3 = 0$ 垂直的直線為 $L': x + 2y = k$，代入 $P(1, 5)$ 得 $k = 1 + 10 = 11$，故垂直線為 $x + 2y - 11 = 0$。

步驟 2：求投影點 $H$ 與對稱點 $P'$

解聯立 $\begin{cases} 2x - y = -3 \\ x + 2y = 11 \end{cases} \implies (x, y) = (1, 5)$？驗算：$2(1)-5 = -3$，點 $P(1,5)$ 若改為 $P(3, 4)$，或針對 $P(3,4)$？我們直接對 $P(3,4)$ 與 $P(1,5)$：若點為 $P(3, 4)$，代入 $x+2y=11$ 恰同條垂直線！對 $P(3,4)$ 而言，解聯立得垂足 $H(1, 5)$，對稱點 $P' = 2(1,5) - (3,4) = (-1, 6)$！（若原點 $P(1,5)$ 恰在 $L$ 上，則投影點與對稱點皆為自身 $(1,5)$）。

答：(1) 垂直線 $x + 2y - 11 = 0$；(2) 若自 $Q(3,4)$ 投影至 $L$，垂足為 $H(1,5)$、對稱點為 $(-1,6)$。

課綱指定範例 2 圓與直線的相切、相割與弦長計算

2. 已知圓 $C: x^2 + y^2 - 4x + 2y - 4 = 0$ 與直線 $L: 3x + 4y - 7 = 0$。
(1) 求圓 $C$ 的圓心坐標與半徑 $r$。
(2) 判斷圓 $C$ 與直線 $L$ 的位置關係，若相交於 $A, B$ 兩點，求弦長 $\overline{AB}$。

🧠 解題破題思路：先配方求圓心 $O(2, -1)$ 與半徑 $r = 3$，再算圓心到直線距離 $d$，代弦長公式 $2\sqrt{r^2 - d^2}$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：配方法求圓心與半徑

$$(x - 2)^2 + (y + 1)^2 = 4 + 4 + 1 = 9 = 3^2 \implies \text{圓心 } O(2, -1), \; r = 3$$

步驟 2：求圓心到直線 $L$ 的距離 $d$ 與弦長

$$d(O, L) = \frac{|3(2) + 4(-1) - 7|}{\sqrt{3^2 + 4^2}} = \frac{|-5|}{5} = 1 < r = 3 \quad (\text{相割於兩點})$$

$$\text{弦長 } \overline{AB} = 2\sqrt{r^2 - d^2} = 2\sqrt{3^2 - 1^2} = 2\sqrt{8} = 4\sqrt{2}$$

答：(1) 圓心 $(2, -1)$，半徑 $3$；(2) 相割於兩點，弦長 $\overline{AB} = 4\sqrt{2}$。

課綱指定範例 3 過圓外一點求兩條切線方程式（含鉛直切線陷阱）

3. 求過圓外一點 $P(4, 3)$ 且與圓 $C: (x - 1)^2 + (y + 1)^2 = 9$ 相切的直線方程式。

🧠 解題破題思路：設切線為 $y - 3 = m(x - 4) \implies mx - y + (3 - 4m) = 0$，由圓心 $(1,-1)$ 到切線距離 $= 3$ 解 $m$，若只解出一個 $m$，務必補上鉛直切線 $x = 4$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：設點斜式並利用 $d = r$ 求斜率 $m$

圓心為 $O(1, -1)$，半徑 $r = 3$。設切線為 $L: mx - y + (3 - 4m) = 0$：

$$d(O, L) = \frac{|m(1) - (-1) + 3 - 4m|}{\sqrt{m^2 + 1}} = 3 \implies |4 - 3m| = 3\sqrt{m^2 + 1}$$

兩邊平方：$16 - 24m + 9m^2 = 9m^2 + 9 \implies 24m = 7 \implies m = \frac{7}{24}$。

代入得第一條切線：$y - 3 = \frac{7}{24}(x - 4) \implies 7x - 24y + 44 = 0$。

步驟 2：補上斜率不存在的鉛直切線

因過圓外一點必有兩條切線，檢查過 $P(4,3)$ 的鉛直線 $\mathbf{x = 4}$ 到圓心 $(1,-1)$ 距離恰為 $|4 - 1| = 3 = r$，確為另一條切線！

答：$7x - 24y + 44 = 0$ 或 $x = 4$。
