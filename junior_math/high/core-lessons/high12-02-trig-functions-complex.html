高中核心單元 15 / 18 • 選修數甲 I • 二、三角函數 (1.1 ~ 3.2)

三角函數與複數極式：弧度扇形、週期圖形、正餘弦疊合與棣美弗定理

從角度制邁向微積分必備的「弧度制（$\pi = 180^\circ$）」！完整掌握六種三角函數的週期與圖形、簡諧波動的正餘弦疊合 $A\sin(\omega t+\theta_0)$，以及複數平面上的旋轉伸縮、棣美弗定理與單位根 $\omega$！

📌 課綱備註：不含不同週期的三角函數疊合（故不談和差化積與積化和差）；複數的 n 次方根不宜做牽涉到根的變形的複雜級數問題。

🎯 課綱核心學習目標

  • ✓熟練弧度（弳）與度數的換算、扇形弧長 $s = r\theta$ 與面積 $A = \frac{1}{2}r^2\theta = \frac{1}{2}rs$ 公式。
  • ✓認識六種三角函數（含 $\cot, \sec, \csc$ 與 $1+\tan^2\theta=\sec^2\theta$）的定義域、值域、週期性質與圖形伸縮平移。
  • ✓能利用和角公式將同週期正餘弦函數疊合為 $a\cos(\omega t)+b\sin(\omega t) = \sqrt{a^2+b^2}\sin(\omega t + \theta_0)$，並求限定範圍內的極值。
  • ✓理解複數平面、複數極式 $r(\cos\theta + i\sin\theta)$ 乘除法的旋轉伸縮幾何意義、棣美弗定理與複數 $n$ 次方根（正 $n$ 邊形頂點）。

1. 生活情境引言：交流電簡諧波疊合與複數平面的「旋轉望遠鏡」

為什麼在複數平面上，乘上 $(\cos\theta + i\sin\theta)$ 就等於把向量逆時針旋轉 $\theta$ 角？

🌊 情境一：同週期正餘弦疊合 ＝ 合成一道振幅為 $\sqrt{a^2+b^2}$ 的水波

課綱第 76 頁指出：同頻率的 $\sin(\omega t)$ 與 $\cos(\omega t)$ 相加後，仍然是同頻率的正弦波：

  • 把係數 $(b, a)$ 看成直角三角形的兩股，斜邊 $\sqrt{a^2+b^2}$ 就是合成波的新振幅 $A$！
  • 因此 $a\cos(\omega t) + b\sin(\omega t) = \sqrt{a^2+b^2}\sin(\omega t + \theta_0)$，最高峰就是 $+A$、最低谷就是 $-A$！

🎡 情境二：複數極式乘法 ＝ 長度相乘、角度相加（課綱核心觀念）

設 $z_1 = r_1(\cos\alpha + i\sin\alpha), \; z_2 = r_2(\cos\beta + i\sin\beta)$：

  • 乘開後實部剛好是 $\cos\alpha\cos\beta - \sin\alpha\sin\beta = \cos(\alpha+\beta)$，虛部剛好是 $\sin(\alpha+\beta)$！
  • 這代表複數相乘在幾何上就是「模長相乘 $r_1r_2$，主幅角相加 $\alpha + \beta$（逆時針旋轉）」！連乘 $n$ 次就得到棣美弗定理 $[r(\cos\theta+i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta)$！

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
弧度扇形與週期函數 $$\pi \text{ 弳} = 180^\circ, \quad s = r\theta, \quad A = \frac{1}{2}r^2\theta = \frac{1}{2}rs$$ • $y = A\sin(\omega x + \phi) + k$ 之週期為 $T = \frac{2\pi}{|\omega|}$，振幅為 $|A|$ • 注意：$\tan x$ 的基本週期為 $\pi$，故 $y = \tan(\omega x + \phi)$ 的週期為 $\mathbf{\frac{\pi}{|\omega|}}$；而 $|\sin x|$ 與 $|\cos x|$ 的週期亦減半為 $\pi$！
同週期正餘弦函數的疊合 $$a\sin x + b\cos x = \sqrt{a^2 + b^2}\sin(x + \phi)$$ 其中 $\cos\phi = \frac{a}{\sqrt{a^2+b^2}}, \; \sin\phi = \frac{b}{\sqrt{a^2+b^2}}$ • 當 $x \in \mathbb{R}$ 時，最大值為 $\sqrt{a^2+b^2}$，最小值為 $-\sqrt{a^2+b^2}$；若有範圍限制，須先求出相角 $x + \phi$ 的區間！
複數極式與棣美弗定理 $$z = a + bi = r(\cos\theta + i\sin\theta), \quad r = |z| = \sqrt{a^2+b^2}$$ $$z_1z_2 = r_1r_2[\cos(\theta_1+\theta_2) + i\sin(\theta_1+\theta_2)]$$ $$[r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta)$$ • 標準極式三大條件：① 模長 $r \ge 0$、② 實部為 $\cos\theta$、虛部為 $\sin\theta$ 且角度相同、③ 中間連接號必為 $+$ 號！
複數的 $n$ 次方根與單位根 $z^n = 1$ 的 $n$ 個根為：$$\omega_k = \cos\frac{2k\pi}{n} + i\sin\frac{2k\pi}{n} \quad (k = 0, 1, \dots, n-1)$$ 且滿足 $1 + \omega + \omega^2 + \cdots + \omega^{n-1} = 0$ • 在複數平面上，$z^n = r(\cos\theta+i\sin\theta)$ 的 $n$ 個根必構成以原點為中心、半徑為 $\sqrt[n]{r}$ 的正 $n$ 邊形頂點！

❌ 錯題盲點 1：將「假極式」直接套用棣美弗定理

常見誤區：看到 $(\sin 20^\circ + i\cos 20^\circ)^9$ 直接把角度乘以 $9$ 寫 $\sin 180^\circ + i\cos 180^\circ$。

✅ 正確課綱觀念：棣美弗定理規定實部必須是 $\cos$、虛部必須是 $\sin$！須先利用餘角化為標準極式 $(\cos 70^\circ + i\sin 70^\circ)^9 = \cos 630^\circ + i\sin 630^\circ = -i$！

❌ 錯題盲點 2：求 $y = \tan(2x + \frac{\pi}{3})$ 的週期時誤代 $\frac{2\pi}{2} = \pi$

常見誤區：把正弦週期公式 $\frac{2\pi}{|\omega|}$ 套用到正切函數上。

✅ 正確課綱觀念：$\tan x$ 的原週期是 $\pi$ 而非 $2\pi$！故 $\tan(2x + \frac{\pi}{3})$ 的週期為 $\mathbf{\frac{\pi}{2}}$！

❌ 錯題盲點 3：限定區間疊合求極值忘記檢查端點與頂點是否在範圍內

常見誤區：當 $0 \le x \le \frac{\pi}{2}$ 時，求 $\sin x - \sqrt{3}\cos x = 2\sin(x - \frac{\pi}{3})$ 的最大值寫 $2$。

✅ 正確課綱觀念：因為 $-\frac{\pi}{3} \le x - \frac{\pi}{3} \le \frac{\pi}{6}$，相角根本碰不到 $\frac{\pi}{2}$！最大值發生在 $x - \frac{\pi}{3} = \frac{\pi}{6}$ 處，為 $2\sin\frac{\pi}{6} = \mathbf{1}$！

課綱指定範例 1 正餘弦疊合與限定區間極值

1. 設 $0 \le x \le \pi$，函數 $f(x) = \sqrt{3}\sin x + \cos x + 1$。
(1) 將 $f(x)$ 化為 $A\sin(x + \phi) + 1$ 的形式。
(2) 求 $f(x)$ 在 $0 \le x \le \pi$ 上的最大值與最小值，以及對應的 $x$ 值。

🧠 解題破題思路：提出 $A = 2$ 疊合為 $2\sin\left(x + \frac{\pi}{6}\right) + 1$，再由 $0 \le x \le \pi$ 確定相角範圍 $\frac{\pi}{6} \le x + \frac{\pi}{6} \le \frac{7\pi}{6}$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：正弦疊合

$$f(x) = 2\left(\frac{\sqrt{3}}{2}\sin x + \frac{1}{2}\cos x\right) + 1 = 2\sin\left(x + \frac{\pi}{6}\right) + 1$$

步驟 2：檢查相角區間 $\left[\frac{\pi}{6}, \frac{7\pi}{6}\right]$ 的極值

• 當 $x + \frac{\pi}{6} = \frac{\pi}{2} \implies x = \frac{\pi}{3}$ 時，$\sin\frac{\pi}{2} = 1$，有最大值 $2(1) + 1 = 3$。

• 當 $x + \frac{\pi}{6} = \frac{7\pi}{6} \implies x = \pi$ 時，$\sin\frac{7\pi}{6} = -\frac{1}{2}$，有最小值 $2\left(-\frac{1}{2}\right) + 1 = 0$。

答：(1) $2\sin\left(x+\frac{\pi}{6}\right)+1$；(2) $x=\frac{\pi}{3}$ 時最大值 $3$，$x=\pi$ 時最小值 $0$。

課綱指定範例 2 複數極式與棣美弗定理高次方運算

2. 試求下列複數之值：
(1) $(1 + \sqrt{3}i)^6$
(2) $\frac{(\cos 15^\circ + i\sin 15^\circ)^4}{(\sin 30^\circ - i\cos 30^\circ)^2}$

🧠 解題破題思路：(1) 提出模長 $r = 2$ 化為 $2(\cos 60^\circ + i\sin 60^\circ)$。(2) 分母是假極式！先用 $\sin 30^\circ = \cos(-60^\circ), \; -\cos 30^\circ = \sin(-60^\circ)$ 轉為標準極式！
🔍 點擊展開完整逐步詳解 ▼

第 (1) 題：

$$(1 + \sqrt{3}i)^6 = [2(\cos 60^\circ + i\sin 60^\circ)]^6 = 2^6(\cos 360^\circ + i\sin 360^\circ) = 64(1 + 0i) = 64$$

第 (2) 題：將分母轉為標準極式

分母 $\sin 30^\circ - i\cos 30^\circ = \frac{1}{2} - \frac{\sqrt{3}}{2}i = \cos(-60^\circ) + i\sin(-60^\circ)$。

$$\text{原式} = \frac{\cos 60^\circ + i\sin 60^\circ}{\cos(-120^\circ) + i\sin(-120^\circ)} = \cos[60^\circ - (-120^\circ)] + i\sin 180^\circ = \cos 180^\circ = -1$$

答：(1) $64$；(2) $-1$。

課綱指定範例 3 複數的 $n$ 次方根與單位根等比級數

3. 設 $\omega = \cos\frac{2\pi}{5} + i\sin\frac{2\pi}{5}$ 為 $z^5 = 1$ 的一個虛根。試求：
(1) $1 + \omega + \omega^2 + \omega^3 + \omega^4$ 之值。
(2) 在複數平面上，$1, \omega, \omega^2, \omega^3, \omega^4$ 五個點所圍成的正五邊形周長（以 $\sin 36^\circ$ 表示）。

🧠 解題破題思路：(1) 由 $z^5 - 1 = (z - 1)(z^4 + z^3 + z^2 + z + 1) = 0$ 且 $\omega \neq 1$ 即得。(2) 正五邊形中心角為 $\frac{360^\circ}{5} = 72^\circ$，單邊長為 $2 \times 1 \times \sin 36^\circ$！
🔍 點擊展開完整逐步詳解 ▼

第 (1) 題：因為 $\omega^5 = 1$ 且 $\omega \neq 1$，由等比級數求和公式（或因式分解）：

$$1 + \omega + \omega^2 + \omega^3 + \omega^4 = \frac{1 - \omega^5}{1 - \omega} = 0$$

第 (2) 題：五個根均勻分布在單位圓（$r = 1$）上，相鄰兩頂點對原點張角為 $72^\circ$，作角平分線得單邊長 $= 2\sin 36^\circ$，故正五邊形周長為 $5 \times 2\sin 36^\circ = 10\sin 36^\circ$。

答：(1) $0$；(2) $10\sin 36^\circ$。
