高中核心單元 17 / 18 • 高三下 • 二次曲線（拋物線、橢圓、雙曲線）

二次曲線（圓錐曲線）：拋物線、橢圓與雙曲線的標準式與平移伸縮

從幾何距離定義出發，一次貫通高三下圓錐曲線三大主角：「到焦點距離＝到準線距離」的拋物線、「到兩焦點距離和 $= 2a$」的橢圓，以及「到兩焦點距離差 $= 2a$」的雙曲線與漸近線！

📌 課綱備註：不含傾斜或退化的二次曲線；不含直線與二次曲線的關係（弦與切線）；不含圓錐曲線的光學性質。

🎯 課綱核心學習目標

  • ✓理解拋物線的幾何定義（動點到焦點 $F$ 與準線 $L$ 等距），熟練標準式 $x^2 = 4cy$ 與 $y^2 = 4cx$ 的頂點、焦點、準線與正焦弦長 $4|c|$。
  • ✓理解橢圓的幾何定義（$\overline{PF_1} + \overline{PF_2} = 2a > 2c$），掌握長軸 $2a$、短軸 $2b$、焦距 $2c$ 的核心關係 $a^2 = b^2 + c^2$ 與標準式。
  • ✓理解雙曲線的幾何定義（$|\overline{PF_1} - \overline{PF_2}| = 2a < 2c$），掌握貫軸 $2a$、共軛軸 $2b$、核心關係 $c^2 = a^2 + b^2$、漸近線與共軛雙曲線。
  • ✓能透過配方法、平移與伸縮變換將二元二次方程式 $ax^2 + cy^2 + dx + ey + f = 0$ 化為標準式並判讀各幾何要素。

1. 生活情境引言：行星橢圓軌道與雙曲線漸近線的「十字導引框」

橢圓跟雙曲線的 $a, b, c$ 平方關係為什麼一個是 $a^2 = b^2 + c^2$，另一個卻是 $c^2 = a^2 + b^2$？

🪐 情境一：誰最長，誰就當畢氏定理的「斜邊」！

永遠記住 $a$ 是中心到頂點、$c$ 是中心到焦點：

  • 橢圓（焦點在肚子裡面）：$a > c$，半長軸 $a$ 最長！所以 $a^2 = b^2 + c^2$，且標準式分母誰比較大，誰就是 $a^2$（決定長軸方向）！
  • 雙曲線（焦點在開口裡面）：$c > a$，半焦距 $c$ 最長！所以 $c^2 = a^2 + b^2$，且標準式誰前面是正號，誰就是貫軸 $a^2$（與 $a, b$ 大小無關）！

✖️ 情境二：雙曲線漸近線與共軛雙曲線——只要把「$= 1$」改成「$= 0$」與「$= -1$」！

課綱第 68 頁強調雙曲線的漸近線與共軛雙曲線：

  • 給定雙曲線 $\frac{(x-h)^2}{a^2} - \frac{(y-k)^2}{b^2} = 1$：
  • • 把右邊的 $1$ 改成 $0$（再因式分解），立刻得到兩條漸近線 $\frac{x-h}{a} \pm \frac{y-k}{b} = 0$！
    • 把右邊的 $1$ 改成 $-1$，立刻得到共用同一組漸近線的共軛雙曲線！

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
拋物線標準式與要素 • 上下開口：$(x - h)^2 = 4c(y - k)$（$c>0$ 向上、$c<0$ 向下），焦點 $(h, k+c)$，準線 $y = k - c$
• 左右開口：$(y - k)^2 = 4c(x - h)$（$c>0$ 向右、$c<0$ 向左），焦點 $(h+c, k)$，準線 $x = h - c$		 • 頂點到焦點的距離＝頂點到準線的距離 $= |c|$；正焦弦長 $= 4|c|$（即一次項係數的絕對值）。
橢圓標準式與要素 定義：$\overline{PF_1} + \overline{PF_2} = 2a \quad (a > c > 0, \; \mathbf{a^2 = b^2 + c^2})$
• 橫橢圓：$\frac{(x-h)^2}{a^2} + \frac{(y-k)^2}{b^2} = 1$，焦點 $(h\pm c, k)$
• 直橢圓：$\frac{(x-h)^2}{b^2} + \frac{(y-k)^2}{a^2} = 1$，焦點 $(h, k\pm c)$		 • 長軸長 $= 2a$，短軸長 $= 2b$，正焦弦長 $= \frac{2b^2}{a}$；將半徑為 $1$ 的單位圓水平伸縮 $a$ 倍、鉛直伸縮 $b$ 倍即得橢圓（面積 $= \pi ab$）。
雙曲線標準式、漸近線與共軛雙曲線 定義：$|\overline{PF_1} - \overline{PF_2}| = 2a \quad (c > a > 0, \; \mathbf{c^2 = a^2 + b^2})$
• 左右開口：$\frac{(x-h)^2}{a^2} - \frac{(y-k)^2}{b^2} = 1$
• 漸近線：$\frac{x-h}{a} \pm \frac{y-k}{b} = 0$
• 共軛雙曲線：$\frac{(x-h)^2}{a^2} - \frac{(y-k)^2}{b^2} = -1$		 • 貫軸長 $= 2a$，共軛軸長 $= 2b$，正焦弦長 $= \frac{2b^2}{a}$；雙曲線上任一點到兩漸近線之距離乘積為定值 $\frac{a^2b^2}{a^2+b^2} = \frac{a^2b^2}{c^2}$。

3. 常見易錯觀念提醒（課綱盲點診斷）

掃除觀念盲點後，點擊右側按鈕可進入「高中數學錯題本」查看實戰錯題

📓 進入本年級個人手寫錯題本 (grade12-calculus.html) →

❌ 錯題盲點 1：拋物線直接把一次項係數當成焦距 $c$（忘記除以 4）

常見誤區：看到 $y^2 = 8x$ 就以為焦點是 $(8, 0)$。

✅ 正確課綱觀念：標準式是 $y^2 = \mathbf{4c}x$！故 $4c = 8 \implies c = 2$，焦點為 $(2, 0)$、準線為 $x = -2$！

❌ 錯題盲點 2：雙曲線用分母大小來判斷 $a^2$ 與 $b^2$

常見誤區：看到 $\frac{x^2}{9} - \frac{y^2}{16} = 1$，以為 $16 > 9$ 所以 $a = 4, b = 3$。

✅ 正確課綱觀念：橢圓才是「誰大誰是 $a^2$」；雙曲線永遠是「正項分母為 $a^2$、負項分母為 $b^2$」！故上式中 $a = 3, b = 4, c = \sqrt{9+16} = 5$！

❌ 錯題盲點 3：動點到兩定點距離和（或差）等於定點距離 $2c$ 時的退化情形

常見誤區：若 $\overline{PF_1}+\overline{PF_2}=6$，而 $\overline{F_1F_2}=6$，誤以為圖形是橢圓。

✅ 正確課綱觀念：當 $2a = 2c$ 時，$\overline{PF_1}+\overline{PF_2}=\overline{F_1F_2}$ 退化為線段 $\overline{F_1F_2}$；而 $|\overline{PF_1}-\overline{PF_2}|=\overline{F_1F_2}$ 則退化為兩側射線！

✍️

課綱指定範例 1 拋物線的定義、標準式與焦點準線判讀

1. 已知拋物線方程式為 $x^2 - 4x - 8y + 20 = 0$。試透過配方法求此拋物線的頂點坐標、焦點坐標、準線方程式與正焦弦長。

🧠 解題破題思路：將含 $x$ 的項配方移到左邊，其餘移到右邊化為 $(x-h)^2 = 4c(y-k)$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：配方法化為標準式

$$(x^2 - 4x + 4) = 8y - 20 + 4 \implies (x - 2)^2 = 8(y - 2)$$

步驟 2：判讀 $c$ 與各要素

• 對照 $(x-h)^2 = 4c(y-k)$，得頂點 $(h, k) = (2, 2)$，且 $4c = 8 \implies c = 2 > 0$（開口向上）。

• 焦點為 $(2, 2 + 2) = (2, 4)$；準線為 $y = 2 - 2 = 0$（即 $x$ 軸）；正焦弦長為 $4|c| = 8$。

答：頂點 $(2,2)$，焦點 $(2,4)$，準線 $y=0$，正焦弦長 $8$。

課綱指定範例 2 橢圓定義與焦點三角形結合餘弦定理

2. 設橢圓方程式為 $\frac{x^2}{25} + \frac{y^2}{9} = 1$，其兩焦點為 $F_1, F_2$。若 $P$ 為橢圓上一點且滿足 $\angle F_1PF_2 = 60^\circ$，試求 $\triangle PF_1F_2$ 的面積。

🧠 解題破題思路：由定義知 $\overline{PF_1} + \overline{PF_2} = 2a = 10$，且 $\overline{F_1F_2} = 2c = 8$；在 $\triangle PF_1F_2$ 中利用餘弦定理與乘法公式求出 $\overline{PF_1}\cdot\overline{PF_2}$ 即可算面積！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：由橢圓標準式求 $a, b, c$

$a^2 = 25 \implies a = 5$，$b^2 = 9 \implies b = 3$，故 $c = \sqrt{25 - 9} = 4$，焦距 $\overline{F_1F_2} = 2c = 8$。

步驟 2：設 $\overline{PF_1}=m, \; \overline{PF_2}=n$，結合橢圓定義與餘弦定理

由定義 $m + n = 2a = 10$。在 $\triangle PF_1F_2$ 中由餘弦定理：

$$8^2 = m^2 + n^2 - 2mn\cos 60^\circ = (m + n)^2 - 3mn = 100 - 3mn$$

$$\implies 3mn = 36 \implies mn = 12$$

$$\triangle PF_1F_2 \text{ 面積} = \frac{1}{2}mn\sin 60^\circ = \frac{1}{2}(12)\left(\frac{\sqrt{3}}{2}\right) = 3\sqrt{3}$$

答：$3\sqrt{3}$。

課綱指定範例 3 雙曲線標準式、漸近線與共軛雙曲線

3. 已知雙曲線 $9x^2 - 16y^2 - 18x - 64y - 199 = 0$。試求此雙曲線的：(1) 中心與兩焦點坐標；(2) 兩條漸近線方程式；(3) 共軛雙曲線的標準式。

🧠 解題破題思路：先對 $x, y$ 分別配方化為 $\frac{(x-1)^2}{16} - \frac{(y+2)^2}{9} = 1$，再將右邊的 $1$ 改為 $0$（漸近線）與 $-1$（共軛雙曲線）！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：配方法化為標準式

$$9(x^2 - 2x + 1) - 16(y^2 + 4y + 4) = 199 + 9 - 64 = 144$$

兩邊同除以 $144$：

$$\frac{(x - 1)^2}{16} - \frac{(y + 2)^2}{9} = 1$$

步驟 2：判讀焦點、漸近線與共軛雙曲線

• (1) 中心為 $(1, -2)$，$a = 4, \; b = 3 \implies c = \sqrt{16 + 9} = 5$（左右開口），兩焦點為 $(1 \pm 5, -2)$，即 $(6, -2)$ 與 $(-4, -2)$。

• (2) 令右式為 $0$：$\frac{x-1}{4} \pm \frac{y+2}{3} = 0 \implies 3x - 4y - 11 = 0$ 與 $3x + 4y + 5 = 0$。

• (3) 共軛雙曲線：$\frac{(x - 1)^2}{16} - \frac{(y + 2)^2}{9} = -1$（即 $\frac{(y+2)^2}{9} - \frac{(x-1)^2}{16} = 1$）。

答：(1) 中心 $(1,-2)$，焦點 $(6,-2), (-4,-2)$；(2) $3x-4y-11=0, \; 3x+4y+5=0$；(3) $\frac{(y+2)^2}{9} - \frac{(x-1)^2}{16} = 1$。
