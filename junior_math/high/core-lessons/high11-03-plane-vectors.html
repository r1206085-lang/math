平面向量：線性組合、內積與餘弦定理、柯西不等式與二階行列式

將幾何問題代數化的終極武器！掌握課綱兩大核心定理：由餘弦定理導出的「向量內積 $\vec{a}\cdot\vec{b}=a_1b_1+a_2b_2$（投影與高）」與由正弦定理導出的「二階行列式 $|a_1b_2-a_2b_1|$（平行四邊形面積與克拉瑪公式）」！

📌 課綱備註：強調內積（餘弦）與行列式（正弦面積）的幾何表現與代數雙線性，並與二元一次聯立方程組連結。

🎯 課綱核心學習目標

  • ✓熟練平面向量的幾何與坐標表示、線性組合 $\vec{c}=x\vec{a}+y\vec{b}$、分點公式、三角形重心與內心向量表示法及直線參數式。
  • ✓理解課綱內積推導：由餘弦定理導出 $\vec{a}\cdot\vec{b} = |\vec{a}||\vec{b}|\cos\theta = a_1b_1 + a_2b_2$，並應用於兩向量垂直判定、正射影、向量直交化與柯西不等式。
  • ✓掌握直線法向量、兩直線夾角與點到直線距離公式的向量證法。
  • ✓理解三角形面積公式 $\frac{1}{2}\sqrt{|\vec{a}|^2|\vec{b}|^2 - (\vec{a}\cdot\vec{b})^2} = \frac{1}{2}|a_1b_2 - a_2b_1|$、二階行列式性質與二階克拉瑪公式。

1. 生活情境引言：斜座標網格（線性組合）與陽光正射影

為什麼課綱說「內積是餘弦定理的代數表現，行列式是正弦定理的代數表現」？

🗺️ 情境一：線性組合 $\vec{OP} = x\vec{a} + y\vec{b}$ ＝ 平行四邊形斜網格

課綱第 63 頁要求標示出 $\left\{x\begin{bmatrix}1\\2\end{bmatrix} + y\begin{bmatrix}2\\1\end{bmatrix} \;\middle|\; 0 \le x \le 1, \; 0 \le y \le 1\right\}$ 的區域：

  • 把 $\vec{a}, \vec{b}$ 當成斜向的一步！當 $0 \le x \le 1$ 且 $0 \le y \le 1$ 時，終點 $P$ 掃過的區域剛好就是由 $\vec{a}, \vec{b}$ 張開的一整塊平行四邊形！
  • 三點共線黃金法則：若 $A, B, P$ 三點共線，則 $\vec{OP} = x\vec{OA} + y\vec{OB} \iff \mathbf{x + y = 1}$！

☀️ 情境二：內積 $\vec{a}\cdot\vec{b}$ 與行列式 $\det(\vec{a}, \vec{b})$ 的雙胞胎關係

給定兩向量 $\vec{a}=(a_1,a_2), \vec{b}=(b_1,b_2)$（課綱～64）：

  • 內積看 $\cos\theta$（投影）：$|\vec{a}||\vec{b}|\cos\theta = a_1b_1 + a_2b_2$，當它等於 $0$ 代表兩向量垂直！
  • 行列式看 $\sin\theta$（面積）：$|\vec{a}||\vec{b}|\sin\theta = |a_1b_2 - a_2b_1|$，當它等於 $0$ 代表張開面積為 $0$，即兩向量平行（聯立方程組無唯一解）！

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
向量分點、重心與三點共線 • 分點公式（$P$ 在 $\overline{AB}$ 上且 $\overline{AP}:\overline{PB}=m:n$）：$$\vec{OP} = \frac{n}{m+n}\vec{OA} + \frac{m}{m+n}\vec{OB}$$ • 重心 $G$：$\vec{OG} = \frac{1}{3}(\vec{OA}+\vec{OB}+\vec{OC})$（且 $\vec{GA}+\vec{GB}+\vec{GC}=\vec{0}$）
• 內心 $I$：$\vec{OI} = \frac{a\vec{OA}+b\vec{OB}+c\vec{OC}}{a+b+c}$		 • $A, B, P$ 三點共線 $\iff \vec{OP} = \alpha\vec{OA} + \beta\vec{OB}$ 且 $\alpha + \beta = 1$。
內積、正射影與直交分解 $$\vec{a}\cdot\vec{b} = |\vec{a}||\vec{b}|\cos\theta = a_1b_1 + a_2b_2$$ • $\vec{a} \perp \vec{b} \iff \vec{a}\cdot\vec{b} = 0$
• $\vec{a}$ 在 $\vec{b}$ 上的正射影 $= \left(\frac{\vec{a}\cdot\vec{b}}{|\vec{b}|^2}\right)\vec{b}$，正射影長 $= \frac{|\vec{a}\cdot\vec{b}|}{|\vec{b}|}$		 • 向量直交化（課綱核心觀念）：將 $\vec{a}$ 分解為平行 $\vec{b}$ 的正射影 $\vec{u} = \frac{\vec{a}\cdot\vec{b}}{|\vec{b}|^2}\vec{b}$ 與垂直 $\vec{b}$ 的分量 $\vec{v} = \vec{a} - \vec{u}$。
柯西不等式與點到直線距離 $$(a_1^2 + a_2^2)(b_1^2 + b_2^2) \ge (a_1b_1 + a_2b_2)^2$$ 等號成立充要條件為 $\frac{a_1}{b_1} = \frac{a_2}{b_2}$（兩向量平行）
$$d(P, L) = \frac{|ax_0 + by_0 + c|}{\sqrt{a^2 + b^2}}$$		 • 直線 $ax + by + c = 0$ 的法向量為 $\vec{n} = (a, b)$，方向向量為 $\vec{v} = (b, -a)$。
三角形面積、二階行列式與克拉瑪公式 $$\triangle OAB = \frac{1}{2}\sqrt{|\vec{a}|^2|\vec{b}|^2 - (\vec{a}\cdot\vec{b})^2} = \frac{1}{2}\left|\begin{vmatrix} a_1 & a_2 \\ b_1 & b_2 \end{vmatrix}\right| = \frac{1}{2}|a_1b_2 - a_2b_1|$$ 聯立方程組 $\Delta \neq 0$ 時：$x = \frac{\Delta_x}{\Delta}, \; y = \frac{\Delta_y}{\Delta}$ • $\Delta \neq 0 \iff$ 恰有一組解；$\Delta = 0$ 且 $\Delta_x = \Delta_y = 0 \iff$ 重合無限多解；$\Delta = 0$ 但 $\Delta_x, \Delta_y$ 不全為 $0 \iff$ 平行無解。

掃除觀念盲點後，點擊右側按鈕可進入「高中數學錯題本」查看實戰錯題

❌ 錯題盲點 1：計算 $\vec{AB} \cdot \vec{BC}$ 時直接代內角 $\cos B$

常見誤區：在邊長為 $2$ 的正 $\triangle ABC$ 中，算 $\vec{AB}\cdot\vec{BC} = 2 \times 2 \times \cos 60^\circ = 2$。

✅ 正確課綱觀念：兩向量求內積必須先平移至始點重合！$\vec{AB}$ 與 $\vec{BC}$ 的夾角是外角 $180^\circ - 60^\circ = 120^\circ$，故 $\vec{AB}\cdot\vec{BC} = 2 \times 2 \times \cos 120^\circ = \mathbf{-2}$！

❌ 錯題盲點 2：正射影公式分母寫成 $|\vec{a}|^2$ 或忘記平方

常見誤區：求 $\vec{a}$ 在 $\vec{b}$ 上的正射影，分母卻除以 $|\vec{a}|^2$。

✅ 正確課綱觀念：「在誰（$\vec{b}$）身上的影子」，方向就是 $\vec{b}$，分母永遠是被投影向量長度的平方 $|\vec{b}|^2$：$\left(\frac{\vec{a}\cdot\vec{b}}{|\vec{b}|^2}\right)\vec{b}$！

❌ 錯題盲點 3：二階克拉瑪公式 $\Delta = 0$ 時直接宣稱無解

常見誤區：看到行列式 $\Delta = 0$ 就回答無解，未檢查 $\Delta_x, \Delta_y$。

✅ 正確課綱觀念：當 $\Delta = 0$ 時代表兩直線平行或重合，必須繼續檢查 $\Delta_x, \Delta_y$ 是否亦為 $0$（全為 $0$ 則重合無限多解，不全為 $0$ 才平行無解）！

課綱指定範例 1 向量的直交化（分解為平行與垂直分量）

1. 已知向量 $\vec{a} = (4, 5), \; \vec{b} = (1, 2)$。試將向量 $\vec{a}$ 分解為與 $\vec{b}$ 平行的分量 $\vec{u}$ 及與 $\vec{b}$ 垂直的分量 $\vec{v}$（使得 $\vec{a} = \vec{u} + \vec{v}$）。

🧠 解題破題思路：與 $\vec{b}$ 平行的分量 $\vec{u}$ 就是 $\vec{a}$ 在 $\vec{b}$ 上的正射影！算出 $\vec{u}$ 後，直接用 $\vec{v} = \vec{a} - \vec{u}$ 就得到垂直分量！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：求 $\vec{a}$ 在 $\vec{b}$ 上的正射影 $\vec{u}$（平行分量）

$$\vec{u} = \left(\frac{\vec{a}\cdot\vec{b}}{|\vec{b}|^2}\right)\vec{b} = \left(\frac{4(1) + 5(2)}{1^2 + 2^2}\right)(1, 2) = \frac{14}{5}(1, 2) = \left(\frac{14}{5}, \frac{28}{5}\right)$$

步驟 2：相減求垂直分量 $\vec{v}$

$$\vec{v} = \vec{a} - \vec{u} = (4, 5) - \left(\frac{14}{5}, \frac{28}{5}\right) = \left(\frac{6}{5}, -\frac{3}{5}\right)$$

（驗算內積：$\vec{v}\cdot\vec{b} = \frac{6}{5}(1) + \left(-\frac{3}{5}\right)(2) = 0$，確實垂直！）

答：平行分量 $\vec{u} = \left(\frac{14}{5}, \frac{28}{5}\right)$，垂直分量 $\vec{v} = \left(\frac{6}{5}, -\frac{3}{5}\right)$。

課綱指定範例 2 柯西不等式求極值與發生時的座標

2. 設實數 $x, y$ 滿足 $x^2 + y^2 = 20$，試求 $2x + 4y$ 的最大值與最小值，並求發生最大值時的 $(x, y)$ 坐標。

🧠 解題破題思路：由柯西不等式 $(x^2+y^2)(2^2+4^2) \ge (2x+4y)^2$，且等號成立時滿足 $\frac{x}{2} = \frac{y}{4}$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：套用二維柯西不等式

$$(x^2 + y^2)(2^2 + 4^2) \ge (2x + 4y)^2 \implies 20 \times 20 \ge (2x + 4y)^2$$

$$\implies -20 \le 2x + 4y \le 20$$

步驟 2：求最大值 $20$ 成立時的 $(x, y)$

等號成立於 $\frac{x}{2} = \frac{y}{4} = k \implies x = 2k, \; y = 4k$，代入 $2x + 4y = 20$ 得 $20k = 20 \implies k = 1$，故 $(x, y) = (2, 4)$。

答：最大值 $20$（此時 $(x,y)=(2,4)$），最小值 $-20$。

課綱指定範例 3 線性組合斜網格面積與二階行列式

3. 設 $\vec{a} = (3, 1), \; \vec{b} = (1, 4)$。若點 $P$ 滿足 $\vec{OP} = x\vec{a} + y\vec{b}$，其中 $-1 \le x \le 2$ 且 $0 \le y \le 3$，試求所有點 $P$ 所構成之區域面積。

🧠 解題破題思路：先用二階行列式 $|a_1b_2 - a_2b_1|$ 算出 $1 \times 1$ 單位平行四邊形面積，再乘上 $x$ 跨度 $(2 - (-1)) = 3$ 倍與 $y$ 跨度 $(3 - 0) = 3$ 倍！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：由二階行列式求 $\vec{a}, \vec{b}$ 張開的單位平行四邊形面積

$$A_0 = \left|\begin{vmatrix} 3 & 1 \\ 1 & 4 \end{vmatrix}\right| = |3 \times 4 - 1 \times 1| = 11$$

步驟 2：乘上係數伸縮倍率

因為 $x$ 的範圍長度為 $2 - (-1) = 3$，$y$ 的範圍長度為 $3 - 0 = 3$：

$$\text{總面積} = 3 \times 3 \times A_0 = 9 \times 11 = 99$$

答：$99$。
