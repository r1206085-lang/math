高中核心單元 06 / 18 • 數學 II • 三、機率 (1.1 ~ 3.1)

機率：古典機率、條件機率、獨立事件與貝氏定理

從拉普拉斯古典機率出發，掌握「縮小樣本空間」的條件機率 $P(B|A)$，並用樹狀圖與分割定理透徹理解課綱兩大經典素養模型——「工廠瑕疵品溯源」與「醫療檢測偽陽性（貝氏定理）」！

📌 課綱備註：不含幾何機率；藉由生活中的實例說明機率基本性質、條件機率與貝氏定理。

🎯 課綱核心學習目標

  • ✓理解樣本空間、事件運算（交集、聯集、互斥、餘事件）與古典機率的定義及加法法則 $P(A\cup B)=P(A)+P(B)-P(A\cap B)$。
  • ✓理解條件機率 $P(B|A) = \frac{P(A\cap B)}{P(A)}$ 的意義與機率乘法法則 $P(A\cap B) = P(A)P(B|A)$。
  • ✓熟練貝氏定理（Bayes' Theorem）與樣本空間分割，解決疾病篩檢陽性率與多生產線瑕疵品來源機率問題。
  • ✓理解獨立事件的定義 $P(A\cap B) = P(A)P(B)$，並能分辨「獨立事件」與「互斥事件」的本質差異。

1. 生活情境引言：縮小放大鏡的視野（條件機率）與快篩陽性的真相

為什麼「90% 準確的檢驗」測出陽性時，真正生病的機率竟然不到 16%？

🔭 情境一：條件機率 $P(B|A)$ ＝ 把宇宙縮小到事件 $A$

原本我們在整個樣本空間 $S$ 看事件 $B$ 的比例；一旦得知「事件 $A$ 已經發生」：

  • $A$ 以外的世界全部作廢！新的分母變成 $P(A)$，而分子必須是同時落在 $A$ 裡面的 $B$，也就是交集 $P(A \cap B)$！
  • 因此 $P(B|A) = \frac{P(A \cap B)}{P(A)} = \frac{n(A \cap B)}{n(A)}$。

🏥 情境二：貝氏定理 ＝ 順向樹狀圖的「逆向溯源」（課綱核心觀念）

全國只有 $2\%$ 的人患病，健康者佔 $98\%$。即使試劑對患病者有 $90\%$ 驗出陽性，對健康者也有 $10\%$ 誤判為偽陽性：

  • 抓 $1000$ 人來測：$20$ 個病人中驗出 $18$ 個真陽性；但 $980$ 個健康人中卻會誤判出 $98$ 個偽陽性！
  • 所以全部 $18 + 98 = 116$ 個陽性者中，真正患病的只有 $\frac{18}{116} \approx 15.5\%$！這就是貝氏定理教我們的理性思辨。

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
古典機率與餘事件性質 $$P(A) = \frac{n(A)}{n(S)}, \quad 0 \le P(A) \le 1, \quad P(A') = 1 - P(A)$$ $$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$ • 遇到「至少發生一件」或「生日相同問題（課綱核心觀念）」，優先使用餘事件 $1 - P(\text{全不發生})$ 計算！
條件機率與乘法法則 $$P(B|A) = \frac{P(A \cap B)}{P(A)} \iff P(A \cap B) = P(A) \cdot P(B|A)$$ • 條件機率對「分子」仍滿足餘事件與取捨性質：$P(B'|A) = 1 - P(B|A)$。
全機率公式與貝氏定理 設 $A_1, A_2, A_3$ 為樣本空間分割，則對事件 $B$：$$P(A_1|B) = \frac{P(A_1)P(B|A_1)}{P(A_1)P(B|A_1) + P(A_2)P(B|A_2) + P(A_3)P(B|A_3)}$$ • 口訣：「分母為所有通往 $B$ 的樹狀圖路徑機率總和，分子為指定來源的那一條路徑機率」！
獨立事件及其等價性質 $$A, B \text{ 獨立} \iff P(A \cap B) = P(A) \cdot P(B) \iff P(B|A) = P(B)$$ • 若 $A, B$ 獨立，則 $(A, B')$、$(A', B)$、$(A', B')$ 亦必兩兩獨立！

❌ 錯題盲點 1：把「互斥事件」與「獨立事件」混為一談

常見誤區：以為 $A, B$ 互斥（$A\cap B = \varnothing$）就代表 $A, B$ 獨立。

✅ 正確課綱觀念：若 $P(A)>0, P(B)>0$：互斥則絕不獨立，獨立則絕不互斥！因為互斥時 $P(A\cap B)=0 \neq P(A)P(B)$（發生 $A$ 就保證 $B$ 絕不發生，彼此影響極大！）。

❌ 錯題盲點 2：計算古典機率時樣本空間元素並非「等可能」

常見誤區：投兩枚相同硬幣，認為「兩正、一正一反、兩反」機率各為 $\frac{1}{3}$。

✅ 正確課綱觀念：計算古典機率時，相同物也必須視為相異（編號）以確保每種結果出現機會均等！兩枚硬幣有 $(正,正), (正,反), (反,正), (反,反)$ 共 $4$ 種等可能結果，一正一反為 $\frac{2}{4}=\frac{1}{2}$。

❌ 錯題盲點 3：將 $P(A'|B')$ 誤寫為 $1 - P(A|B)$

常見誤區：對條件機率的條件部分直接取補集。

✅ 正確課綱觀念：補集公式只對斜線左邊的目標事件成立：$P(A'|B) = 1 - P(A|B)$；若斜線右邊條件改變為 $B'$，分母完全不同，必須重新計算 $\frac{P(A'\cap B')}{P(B')}$！

課綱指定範例 1 工廠生產線與貝氏定理

1. 某公司的產品分別由 A、B、C 三工廠提供，其中 A 廠提供 $40\%$、B 廠提供 $30\%$、C 廠提供 $30\%$；而 A 廠產品有 $5\%$ 瑕疵品、B 廠有 $10\%$ 瑕疵品、C 廠有 $8\%$ 瑕疵品。若從該公司產品中隨機抽出一件發現為瑕疵品，則此瑕疵品是由 A 工廠製造的機率為何？

🧠 解題破題思路：畫出三條分支路徑：A 廠瑕疵 $0.4 \times 0.05$、B 廠瑕疵 $0.3 \times 0.10$、C 廠瑕疵 $0.3 \times 0.08$，三者相加當分母，A 廠當分子！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：計算各廠產生瑕疵品的交集機率

• $P(A \cap D) = 0.40 \times 0.05 = 0.020$

• $P(B \cap D) = 0.30 \times 0.10 = 0.030$

• $P(C \cap D) = 0.30 \times 0.08 = 0.024$

步驟 2：由貝氏定理求 $P(A|D)$

$$P(A|D) = \frac{0.020}{0.020 + 0.030 + 0.024} = \frac{0.020}{0.074} = \frac{20}{74} = \frac{10}{37}$$

答：$\frac{10}{37}$。

課綱指定範例 2 醫療檢驗準確率與貝氏定理

2. 某一檢查方法對檢驗某疾病有 $90\%$ 的準確率（即患病者有 $90\%$ 呈陽性，未患病者也有 $90\%$ 呈陰性）。已知全國人口中有 $2\%$ 患有該疾病，若有一人檢查結果為陽性，則他確實罹患該病的機率為何？

🧠 解題破題思路：注意「未患病者 $90\%$ 呈陰性」代表「未患病者有 $1 - 90\% = 10\%$ 會誤判為偽陽性」！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：分解真陽性與偽陽性機率

• 患病且陽性（真陽性）：$P(\text{病} \cap +) = 0.02 \times 0.90 = 0.018$

• 未患病但陽性（偽陽性）：$P(\text{無病} \cap +) = 0.98 \times 0.10 = 0.098$

步驟 2：由貝氏定理求陽性下真正患病機率

$$P(\text{病}|+) = \frac{0.018}{0.018 + 0.098} = \frac{0.018}{0.116} = \frac{18}{116} = \frac{9}{58} \approx 15.52\%$$

答：$\frac{9}{58}$（約 $15.52\%$）。

課綱核心範例 3 獨立事件的聯集與餘事件

3. 設甲、乙兩人獨立解同一道數學題，甲解出的機率為 $\frac{2}{3}$，乙解出的機率為 $\frac{3}{4}$。試求：
(1) 兩人中恰有一人解出的機率。
(2) 此題被解出（至少一人解出）的機率。

🧠 解題破題思路：因甲、乙獨立，故 $(甲, 乙')$、$(甲', 乙)$、$(甲', 乙')$ 皆獨立，直接相乘即可！
🔍 點擊展開完整逐步詳解 ▼

第 (1) 題（恰有一人解出）：

$$P(A\cap B') + P(A'\cap B) = \frac{2}{3}\left(1 - \frac{3}{4}\right) + \left(1 - \frac{2}{3}\right)\frac{3}{4} = \frac{2}{12} + \frac{3}{12} = \frac{5}{12}$$

第 (2) 題（至少一人解出＝1－兩人都沒解出）：

$$1 - P(A'\cap B') = 1 - \left(1 - \frac{2}{3}\right)\left(1 - \frac{3}{4}\right) = 1 - \frac{1}{12} = \frac{11}{12}$$

答：(1) $\frac{5}{12}$；(2) $\frac{11}{12}$。
