高中核心單元 02 / 18 • 數學 I • 二、多項式函數 (1.1 ~ 4.1)

多項式函數：綜合除法、插值多項式、勘根定理與圖形不等式

從一次與二次函數的正定性（恆正性）、單項函數 $y=cx^n(n\le 4)$ 平移出發，貫通連續綜合除法求近似值、牛頓與拉格朗日插值多項式、虛根成對與勘根定理，以及已分解高次不等式。

📌 課綱備註：單項函數僅至 4 次且不涉及二項式展開逆運算；插值多項式不超過三次；不含最高公因式與複雜分式不等式。

🎯 課綱核心學習目標

  • ✓理解二次式的正定性（恆正性 $a>0, D<0$）與單項函數 $y = c(x-h)^n + k \; (n=1,2,3,4)$ 的奇偶性、單調性與平移。
  • ✓熟練綜合除法、餘式與因式定理、連續綜合除法求 $f(a)$ 附近近似值，以及牛頓與拉格朗日插值多項式。
  • ✓掌握二次方程式複數根、有理根判定法、勘根定理求實根近似區間，以及實係數多項式虛根成對定理。
  • ✓能辨識已分解多項式函數圖形特徵（零根、重根奇穿偶切、正負區間）並解高次與簡易分式不等式。

1. 生活情境引言：局部放大鏡與數據點描繪曲線

為什麼連續除以 $(x-a)$ 就能算近似值？三筆離散氣溫數據怎麼還原出連續溫度曲線？

🔍 情境一：連續綜合除法 ＝ 在 $x = a$ 架設局部放大鏡

將 $f(x) = 2x^3 - 5x^2 + 6x + 3$ 透過連續除以 $(x-1)$ 展開為 $a + b(x-1) + c(x-1)^2 + d(x-1)^3$：

  • 當 $x = 1.01$ 時，$x - 1 = 0.01$，平方與立方項 $(0.01)^2 = 10^{-4}, (0.01)^3 = 10^{-6}$ 微乎其微！
  • 因此只要取前兩項 $a + b(x-1)$ 就能瞬間得到極為精準的局部近似值！

📈 情境二：插值多項式 ＝ 離散觀測點的「平滑連連看」

已知函數圖形通過 $(1,1), (2,3), (3,7)$ 三個點，如何找出不超過二次的唯一拋物線？

  • 牛頓插值法：像疊積木一樣設 $f(x) = a + b(x-1) + c(x-1)(x-2)$，依序代入 $x=1,2,3$ 即可逐一求出係數！
  • 拉格朗日插值法：直接構造在該點為 $1$、其餘觀測點為 $0$ 的分式基底組合而成，一步到位！

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
二次式正定性與單項函數平移 • 二次式恆正：$ax^2+bx+c > 0 \iff a > 0 \text{ 且 } D = b^2-4ac < 0$
• 單項函數平移：$y = c(x-h)^n + k \quad (n=1,2,3,4)$		 • 當 $n$ 為奇數時 $y=cx^n$ 對稱於原點（奇函數）；當 $n$ 為偶數時對稱於 $y$ 軸（偶函數）。
• 課綱備註：不涉及二項式展開的逆運算。
除法原理、餘式與因式定理 $$f(x) = g(x)q(x) + r(x), \quad \deg r(x) < \deg g(x) \text{ 或 } r(x)=0$$ • 除以 $(x-a)$ 餘式為 $f(a)$；$(x-a) \mid f(x) \iff f(a) = 0$ • $f(x)$ 除以 $(x-a)(x-b)$ 的餘式，即為通過 $(a, f(a)), (b, f(b))$ 的一次插值多項式。
牛頓與拉格朗日插值多項式 • 牛頓型：$f(x) = a + b(x-x_1) + c(x-x_1)(x-x_2)$
• 拉格朗日型：$f(x) = \sum_{i=1}^{3} y_i \prod_{j \neq i} \frac{x-x_j}{x_i-x_j}$		 • 由因式定理可證：通過相異 $n+1$ 點且次數 $\le n$ 的插值多項式必唯一（課綱限制次數不超過三次）。
勘根定理與虛根成對定理 • 勘根定理：實係數 $f(x)$ 若 $f(a)f(b) < 0$，則 $(a,b)$ 內至少有一實根。
• 虛根成對：實係數 $f(\alpha+\beta i)=0 \implies f(\alpha-\beta i)=0$。		 • 已分解高次不等式 $(x-a_1)^{r_1}(x-a_2)^{r_2} > 0$：奇次重根穿過 $x$ 軸變號，偶次重根相切不變號。

3. 常見易錯觀念提醒（課綱盲點診斷）

掃除觀念盲點後，點擊右側按鈕可進入「高中數學錯題本」查看實戰錯題

📓 進入本年級個人手寫錯題本 (grade10-algebra.html) →

❌ 錯題盲點 1：以為 $f(a)f(b) > 0$ 就代表 $(a,b)$ 之間無實根

常見誤區：勘根定理逆敘述誤用。

✅ 正確課綱觀念：$f(a)f(b) < 0$ 代表有奇數個實根；若 $f(a)f(b) > 0$，在 $(a,b)$ 內仍可能有偶數個相異實根或偶次重根！

❌ 錯題盲點 2：忽略虛根成對定理的「實係數」前提

常見誤區：對虛係數方程式 $x^2 - ix + 2 = 0$ 直接套用共軛虛根。

✅ 正確課綱觀念：只有實係數多項式才滿足 $\overline{f(z)} = f(\bar{z})$，故虛根成對定理僅適用於實係數多項式！

❌ 錯題盲點 3：誤以為整係數多項式的實根都是有理根

常見誤區：用牛頓法找不出有理根就宣稱無實根。

✅ 正確課綱觀念：課綱強調：找不出有理根時，方程式仍常有無理實根（如 $x^3+2x^2+3x+4=0$），須用勘根定理定位！

❌ 錯題盲點 4：簡易分式不等式 $\frac{1}{x-1} < 1$ 直接乘開分母

常見誤區：兩邊同乘 $(x-1)$ 得 $1 < x - 1 \implies x > 2$，漏掉負分母區間。

✅ 正確課綱觀念：必須移項通分 $\frac{2-x}{x-1} < 0 \implies (x-2)(x-1) > 0$，得完整正解 $x > 2 \text{ 或 } x < 1$！

課綱指定範例 1 連續綜合除法與多項式近似值

1. 設 $f(x) = 2x^3 - 5x^2 + 6x + 3 = a + b(x - 1) + c(x - 1)^2 + d(x - 1)^3$，求 $a, b, c, d$ 之值與 $f(1.01)$ 的二位小數近似值。

🧠 解題破題思路：以 $x = 1$ 做連續三次綜合除法，由下而上（或由內而外）的餘數依序為 $a, b, c, d$。
🔍 點擊展開完整逐步詳解 ▼

步驟 1：連續除以 $(x-1)$

• $2x^3 - 5x^2 + 6x + 3 = (x-1)(2x^2 - 3x + 3) + 6 \implies a = 6$。

• $2x^2 - 3x + 3 = (x-1)(2x - 1) + 2 \implies b = 2$。

• $2x - 1 = 2(x - 1) + 1 \implies c = 1, \; d = 2$。

步驟 2：代入 $x = 1.01$ 求近似值

$$f(1.01) = 6 + 2(0.01) + 1(0.01)^2 + 2(0.01)^3 = 6.020102 \approx 6.02$$

答：$(a,b,c,d) = (6, 2, 1, 2)$；$f(1.01) \approx 6.02$。

課綱指定範例 2 牛頓插值與拉格朗日插值多項式

2. (1) 設通過 $(1,1), (2,3), (3,7)$ 的多項式為 $f(x) = a + b(x-1) + c(x-1)(x-2)$，求 $a,b,c$ 及 $f\left(\frac{1}{2}\right)$。
(2) 設通過 $(11,3), (12,5), (13,8)$ 的拉格朗日插值多項式為 $g(x)$，求 $g(11.5)$ 之值。

🧠 解題破題思路：(1) 依序代入 $x=1,2,3$ 求 $a,b,c$。(2) 代入拉格朗日三項分式求 $x=11.5$ 之值。
🔍 點擊展開完整逐步詳解 ▼

第 (1) 題：代入 $x=1 \Rightarrow a=1$；代入 $x=2 \Rightarrow 1+b=3 \Rightarrow b=2$；代入 $x=3 \Rightarrow 1+4+2c=7 \Rightarrow c=1$。故 $f\left(\frac{1}{2}\right) = 1 + 2\left(-\frac{1}{2}\right) + \left(-\frac{1}{2}\right)\left(-\frac{3}{2}\right) = \frac{3}{4}$。

第 (2) 題：

$$g(11.5) = 3\cdot\frac{(-0.5)(-1.5)}{(-1)(-2)} + 5\cdot\frac{(0.5)(-1.5)}{(1)(-1)} + 8\cdot\frac{(0.5)(-0.5)}{(2)(1)} = \frac{9 + 30 - 8}{8} = \frac{31}{8} = 3.875$$

答：(1) $(a,b,c)=(1,2,1), \; f\left(\frac{1}{2}\right)=\frac{3}{4}$；(2) $g(11.5) = 3.875$。

課綱指定範例 3 複數求值與已分解高次不等式

3. (1) 求 $f(x) = 5x^4 - 21x^3 + 30x^2 - 9x + 7$ 在 $x = 2 + i$ 的值。
(2) 解不等式 $(x - 1)(x + 2)^2(x - 4) > 0$。

🧠 解題破題思路：(1) 由 $(x-2)^2 = i^2 = -1 \implies x^2 - 4x + 5 = 0$ 作除法求餘式。(2) 注意偶次重根 $(x+2)^2 \ge 0$ 在 $x = -2$ 為 $0$。
🔍 點擊展開完整逐步詳解 ▼

第 (1) 題：因 $x = 2 + i \implies x^2 - 4x + 5 = 0$，將 $f(x)$ 除以 $x^2 - 4x + 5$ 得：

$$f(x) = (x^2 - 4x + 5)(5x^2 - x + 1) + 2 \implies f(2+i) = 0 + 2 = 2$$

第 (2) 題：因對 $x \neq -2$ 時 $(x+2)^2 > 0$ 恆正，故由 $(x-1)(x-4) > 0$ 且 $x \neq -2$ 得：$x > 4$ 或 $x < 1$ 且 $x \neq -2$。

答：(1) $2$；(2) $x > 4$ 或 $x < -2$ 或 $-2 < x < 1$。
