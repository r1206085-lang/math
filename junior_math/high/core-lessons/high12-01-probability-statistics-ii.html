機率統計 II：隨機變數、期望值、二項分布與常態分布信賴區間

從離散型隨機變數與機率質量函數出發，掌握期望值 $E(X)$ 與變異數 $\text{Var}(X)$ 的線性變換，貫通伯努利重複試驗「二項分布 $B(n,p)$」，並藉由中央極限定理直觀解讀民調常態分布與 $95\%$ 信賴區間！

📌 課綱備註：高中只處理離散型隨機變數；不含系統抽樣、部落抽樣；統計推論只做期望值估計與信賴區間、信心水準的通識解讀。

🎯 課綱核心學習目標

  • ✓理解離散型隨機變數 $X$、機率質量函數 $P(X=x_i)$、期望值 $E(X) = \sum x_i p_i$ 與變異數 $\text{Var}(X) = E(X^2)-[E(X)]^2$ 的意義。
  • ✓熟練獨立重複試驗與二項分布 $P(X=k) = C^n_k p^k (1-p)^{n-k}$，並直接由公式求出期望值 $\mu = np$ 與標準差 $\sigma = \sqrt{np(1-p)}$。
  • ✓認識簡單隨機抽樣與亂數表的使用，理解中央極限定理使二項分布在 $n$ 很大時趨近常態分布鐘形曲線的直觀意義。
  • ✓能正確計算並解讀母體比例 $p$ 的 $95\%$ 信賴區間 $\left[\hat{p} - 2\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}, \; \hat{p} + 2\sqrt{\frac{\hat{p}(1-\hat{p})}{n}}\right]$ 與信心水準。

1. 生活情境引言：彩券公平定價（期望值）與新聞民調「抽樣誤差 ±3%」的真相

為什麼已經開出來的具體一個 95% 信賴區間，絕對不能說「母體比例 p 落在裡面的機率是 95%」？

🎰 情境一：二項分布 ＝ 投籃 $n$ 次進球數的「完美公式」

如果單次投籃命中率固定為 $p$，連續獨立投 $n$ 球，進球數 $X$ 服從二項分布 $B(n,p)$：

  • 不必把 $k = 0, 1, \dots, n$ 每一項機率乘上 $k$ 慢慢加！直接用期望值 $\mu = np$、變異數 $\sigma^2 = np(1-p)$ 一秒鐘算出平均進幾球與穩定度！

📊 情境二：課綱信賴區間＝「套圈圈遊戲」（母體 $p$ 是固定木樁！）

母體支持率 $p$ 是一根釘死在地上不會動的木樁（常數），而每次抽樣算出的信賴區間則是你丟出去的圈圈：

  • $95\%$ 信心水準的意思是：「如果我們重複抽樣丟出 $100$ 個圈圈，大約有 $95$ 個圈圈會套中木樁 $p$」！
  • 一旦某一次民調已經算出了具體區間（例如 $[0.42, 0.48]$），這個圈圈已經落地不動了，$p$ 要嘛在裡面、要嘛不在裡面，絕對不能說『$p$ 落在 $[0.42, 0.48]$ 的機率是 $95\%$』！

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
隨機變數期望值與變異數 $$E(X) = \mu = \sum x_i p_i, \quad \text{Var}(X) = \sigma^2 = \sum (x_i - \mu)^2 p_i = E(X^2) - [E(X)]^2$$ • 線性變換：$E(aX + b) = aE(X) + b, \quad \text{Var}(aX + b) = a^2\text{Var}(X), \quad \sigma_{aX+b} = |a|\sigma_X$ • 期望值具有線性可加性：$E(X + Y) = E(X) + E(Y)$。
二項分布 $X \sim B(n, p)$ 獨立重複試驗 $n$ 次，每次成功機率 $p$、失敗機率 $q = 1-p$：$$P(X = k) = C^n_k p^k q^{n-k} \quad (k = 0, 1, \dots, n)$$ $$E(X) = np, \quad \text{Var}(X) = np(1-p), \quad \sigma_X = \sqrt{np(1-p)}$$ • 由二項式定理 $\sum_{k=0}^n C^n_k p^k q^{n-k} = (p+q)^n = 1^n = 1$ 驗證總機率為 $1$。
母體比例 $p$ 的信賴區間 設樣本數為 $n$，樣本比例為 $\hat{p}$，標準誤 $SE = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$：
• $68\%$ 信賴區間：$[\hat{p} - SE, \; \hat{p} + SE]$
• $95\%$ 信賴區間：$[\hat{p} - 2SE, \; \hat{p} + 2SE]$
• $99.7\%$ 信賴區間：$[\hat{p} - 3SE, \; \hat{p} + 3SE]$		 • 若要使抽樣誤差（半寬度）縮小為原來的 $\frac{1}{k}$，則抽樣人數 $n$ 必須放大為原來的 $k^2$ 倍！

❌ 錯題盲點 1：錯誤解讀信賴區間為「參數 $p$ 落在該區間內的機率為 95%」

常見誤區：學測與分科測驗最常考的觀念是非題！

✅ 正確課綱觀念：母體參數 $p$ 是未知的定值（非隨機變數），已經算出來的單一信賴區間不包含隨機性，不能談機率 $95\%$！

❌ 錯題盲點 2：計算 $\text{Var}(aX + b)$ 時忘記將係數 $a$ 平方或把 $+b$ 加進去

常見誤區：誤寫 $\text{Var}(3X + 5) = 3\text{Var}(X) + 5$。

✅ 正確課綱觀念：平移 $+5$ 不改變分散程度，而變異數有平方單位，故 $\text{Var}(3X + 5) = 3^2\text{Var}(X) = \mathbf{9\text{Var}(X)}$！

❌ 錯題盲點 3：將「抽一枚硬幣給 100 元」與「抽 100 枚硬幣各給 1 元」變異數當成一樣

常見誤區：混淆 $100X_1$ 與 $X_1 + X_2 + \cdots + X_{100}$。

✅ 正確課綱觀念：兩者期望值雖相同，但 $\text{Var}(100X_1) = 100^2 \sigma^2 = 10000\sigma^2$，而獨立和 $\text{Var}(X_1+\cdots+X_{100}) = 100\sigma^2$，風險相差 $100$ 倍！

課綱指定範例 1 二項分布期望值、標準差與線性變換

1. 某籃球選手每次罰球命中的機率皆為 $0.8$，且每次罰球結果互相獨立。若該選手進行 $100$ 次罰球，每投進一球可得獎金 $50$ 元，沒投進則倒扣 $10$ 元。設投進球數為隨機變數 $X$，總獎金為 $Y$ 元，求 $X$ 與 $Y$ 的期望值與標準差。

🧠 解題破題思路：先由 $X \sim B(100, 0.8)$ 算出 $E(X) = np$ 與 $\sigma_X = \sqrt{np(1-p)}$；再將獎金寫成 $X$ 的一次函數 $Y = 50X - 10(100 - X) = 60X - 1000$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：求進球數 $X \sim B(100, 0.8)$ 的期望值與標準差

$$E(X) = np = 100 \times 0.8 = 80$$

$$\sigma_X = \sqrt{np(1-p)} = \sqrt{100 \times 0.8 \times 0.2} = \sqrt{16} = 4$$

步驟 2：建立總獎金函數 $Y = 50X - 10(100 - X) = 60X - 1000$

$$E(Y) = 60E(X) - 1000 = 60(80) - 1000 = 3800 \text{ 元}$$

$$\sigma_Y = |60|\sigma_X = 60 \times 4 = 240 \text{ 元}$$

答：$E(X)=80, \; \sigma_X=4$；獎金期望值 $3800$ 元，標準差 $240$ 元。

課綱指定範例 2 常態分布近似與 95% 信賴區間計算

2. 某電視台為了解某候選人的支持度 $p$，隨機成功訪問了 $n = 400$ 位選民，其中有 $240$ 人表示支持。試求母體支持度 $p$ 的 $95\%$ 信賴區間（以兩倍標準誤計算）；若希望在相同樣本比例下將最大抽樣誤差縮小為原來的一半，則抽樣人數應增加為多少人？

🧠 解題破題思路：樣本比例 $\hat{p} = \frac{240}{400} = 0.6$，先算標準誤 $SE = \sqrt{\frac{0.6 \times 0.4}{400}}$；誤差縮小為 $\frac{1}{2}$ 時，樣本數須變為 $2^2 = 4$ 倍！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：求樣本比例 $\hat{p}$ 與標準誤 $SE$

$$\hat{p} = \frac{240}{400} = 0.6, \quad SE = \sqrt{\frac{0.6 \times (1 - 0.6)}{400}} = \frac{\sqrt{0.24}}{20} \approx \frac{0.49}{20} = 0.0245$$

步驟 2：求 $95\%$ 信賴區間與抽樣人數倍數

• $95\%$ 信賴區間為 $[0.6 - 2(0.0245), \; 0.6 + 2(0.0245)] = [0.551, \; 0.649]$。

• 誤差與 $\frac{1}{\sqrt{n}}$ 成正比，欲使誤差減半，樣本數須變為 $2^2 = 4$ 倍，即 $400 \times 4 = 1600$ 人。

答：$95\%$ 信賴區間為 $[0.551, \; 0.649]$；抽樣人數應增為 $1600$ 人。

課綱核心範例 3 離散隨機變數的期望值與變異數計算

3. 袋中有 $3$ 顆紅球與 $2$ 顆白球，今從袋中隨機一次取出 $2$ 顆球，設取出的紅球顆數為隨機變數 $X$，試寫出 $X$ 的機率質量函數，並求期望值 $E(X)$ 與變異數 $\text{Var}(X)$。

🧠 解題破題思路：$X$ 可能值為 $0, 1, 2$，分母為 $C^5_2 = 10$，分別算出機率後驗證總和為 $1$，再代 $E(X)$ 與 $E(X^2) - [E(X)]^2$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：求機率質量函數

$$P(X=0)=\frac{C^3_0 C^2_2}{C^5_2}=\frac{1}{10}, \quad P(X=1)=\frac{C^3_1 C^2_1}{C^5_2}=\frac{6}{10}, \quad P(X=2)=\frac{C^3_2 C^2_0}{C^5_2}=\frac{3}{10}$$

步驟 2：求 $E(X)$ 與 $\text{Var}(X)$

$$E(X) = 0\cdot\frac{1}{10} + 1\cdot\frac{6}{10} + 2\cdot\frac{3}{10} = \frac{12}{10} = \frac{6}{5}$$

$$E(X^2) = 0^2\cdot\frac{1}{10} + 1^2\cdot\frac{6}{10} + 2^2\cdot\frac{3}{10} = \frac{18}{10} = \frac{9}{5}$$

$$\text{Var}(X) = E(X^2) - [E(X)]^2 = \frac{9}{5} - \frac{36}{25} = \frac{9}{25}$$

答：$E(X) = \frac{6}{5}, \; \text{Var}(X) = \frac{9}{25}$。
