高中核心單元 18 / 18 • 選修數甲 II • 二、多項式函數的微積分 (1.1 ~ 4.1)

多項式函數的微積分：導數切線、極值反曲點繪圖与定積分旋轉體體積

高中三年數學的巔峰統整！以一階導數 $f'(x)$ 判讀切線斜率與極值、二階導數 $f''(x)$ 判讀凹凸性與三次函數反曲點（對稱中心）；再藉由微積分基本定理，一舉推導出圓面積 $\pi R^2$、球體體積 $\frac{4}{3}\pi R^3$ 與角錐體積 $\frac{1}{3}AH$！

📌 課綱備註：定積分與不定積分的計算不涉及分部積分與變數變換法；附錄含牛頓求根法。

🎯 課綱核心學習目標

  • ✓理解導數定義 $f'(a) = \lim_{x\to a}\frac{f(x)-f(a)}{x-a}$ 的切線斜率與瞬時速度意涵，熟練多項式微分公式與乘法規則 $(fg)' = f'g + fg'$。
  • ✓掌握一階導數檢定法（遞增遞減、相對極大與極小值）與二階導數檢定法（凹向上、凹向下與反曲點），完整描繪三次與四次多項式函數圖形。
  • ✓理解定積分的黎曼上下和極限意義、微積分基本定理 $\int_a^b f(x)\,dx = F(b) - F(a)$ 與兩曲線所圍面積計算。
  • ✓能以切片積分法推導並計算圓面積、球體體積 $\frac{4}{3}\pi R^3$、角錐體積 $\frac{1}{3}AH$、旋轉體體積 $\pi\int_a^b [f(x)]^2\,dx$ 及自由落體運動。
💡

1. 生活情境引言：汽車時速表（微分）與里程表（積分）的互逆奇蹟

國中背過的「球體體積 $\frac{4}{3}\pi R^3$」與「角錐體積 $\frac{1}{3}AH$」，怎麼用定積分三行算出來？

🚗 情境一：微積分基本定理 ＝「時速表」與「總里程」互為逆運算（課綱核心觀念）

對位置函數 $s(t)$ 微分得到瞬時速度 $v(t) = s'(t)$；反過來，把速度函數 $v(t)$ 對時間積分：

  • 無窮多個微小時間段走過的距離 $v(t)\,dt$ 累加起來 $\int_a^b v(t)\,dt$，剛好就等於終點位置減起點位置 $s(b) - s(a)$！
  • 這讓我們不必再硬算複雜的 $\Sigma k^2$ 黎曼上下和，只要找反導函數 $F'(x) = f(x)$ 就能秒殺面積與體積！

🍉 情境二：課綱切片積分法——把球體與角錐切成無數薄片！

半徑為 $R$ 的球體，在座標 $x$ 處垂直切一刀，截面是一個半徑為 $r = \sqrt{R^2 - x^2}$ 的圓盤：

  • 單片圓盤面積為 $\pi r^2 = \pi(R^2 - x^2)$，從 $-R$ 積分到 $R$：$$V = \int_{-R}^R \pi(R^2 - x^2)\,dx = \pi\left[R^2x - \frac{1}{3}x^3\right]_{-R}^R = \frac{4}{3}\pi R^3$$
  • 同理，高為 $H$、底面積為 $A$ 的角錐，在高度 $z$ 處截面積為 $A(z) = A\left(\frac{z}{H}\right)^2$，從 $0$ 積分到 $H$ 立刻得出 $\mathbf{\frac{1}{3}AH}$！
📘

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
導數定義、微分公式與切線 $$f'(a) = \lim_{x\to a}\frac{f(x)-f(a)}{x-a} = \lim_{h\to 0}\frac{f(a+h)-f(a)}{h}$$ $$(x^n)' = nx^{n-1}, \quad [f(x)g(x)]' = f'(x)g(x) + f(x)g'(x)$$ 過曲線上一點 $(a, f(a))$ 之切線：$y - f(a) = f'(a)(x - a)$ • 若函數 $f(x)$ 在 $x = a$ 可微分，則在 $x = a$ 必連續；但連續未必可微分（如 $f(x) = |x|$ 在 $x = 0$ 處尖點不可微）。
極值、凹凸性與反曲點檢定 • 遞增／遞減：$f'(x) > 0 \implies$ 嚴格遞增；$f'(x) < 0 \implies$ 嚴格遞減
• 相對極值：$f'(a) = 0$ 且 $f'(x)$ 在 $a$ 兩側變號（或 $f''(a) < 0$ 極大、$f''(a) > 0$ 極小）
• 反曲點：$f''(a) = 0$ 且 $f''(x)$ 在 $a$ 兩側變號		 • 三次多項式 $f(x) = ax^3+bx^2+cx+d$ 必有唯一反曲點 $x = -\frac{b}{3a}$，且該反曲點即為三次函數圖形的對稱中心！
微積分基本定理與曲線圍面積 若 $F'(x) = f(x)$，則：$$\int_a^b f(x)\,dx = \left[F(x)\right]_a^b = F(b) - F(a), \quad \int x^n\,dx = \frac{1}{n+1}x^{n+1} + C$$ 兩曲線在 $[a,b]$ 所圍面積：$$A = \int_a^b |f(x) - g(x)|\,dx$$ • 三次與二次拋物線面積速算公式（驗算神器）：拋物線 $y = ax^2+bx+c$ 與直線交於 $\alpha < \beta$ 所圍面積恆為 $\mathbf{\frac{|a|}{6}(\beta - \alpha)^3}$！
旋轉體體積與積分應用 繞 $x$ 軸旋轉一圈之旋轉體體積：$$V = \pi\int_a^b [f(x)]^2\,dx$$ • 球體體積：$\frac{4}{3}\pi R^3$；角錐體積：$\frac{1}{3}AH$ • 運動學關係：速度 $v(t) = s'(t)$，加速度 $a(t) = v'(t) = s''(t)$；位移 $= \int_{t_1}^{t_2} v(t)\,dt$，路徑長 $= \int_{t_1}^{t_2} |v(t)|\,dt$。

3. 常見易錯觀念提醒（課綱盲點診斷）

掃除觀念盲點後，點擊右側按鈕可進入「高中數學錯題本」查看實戰錯題

📓 進入本年級個人手寫錯題本 (grade12-calculus.html) →

❌ 錯題盲點 1：以為「$f'(a) = 0$ 就代表 $x = a$ 是極值點」或「$f''(a) = 0$ 就代表是反曲點」

常見誤區：看到 $f(x) = x^3$ 在 $x=0$ 處 $f'(0)=0$ 就當成極值點，或看到 $g(x) = x^4$ 在 $x=0$ 處 $g''(0)=0$ 就當成反曲點。

✅ 正確課綱觀念：導數為 $0$ 只是必要條件！必須確認在 $x = a$ 左右兩側一階導數 $f'(x)$ 有正負變號才是極值點（$x^3$ 無極值）；二階導數 $f''(x)$ 有正負變號才是反曲點（$x^4$ 在 $x=0$ 是極小值點而非反曲點）！

❌ 錯題盲點 2：過「曲線外一點 $P$」求切線時，直接把外點 $P$ 代入 $f'(x)$ 當斜率

常見誤區：題目給曲線外一點 $P(1, 0)$，卻直接算 $f'(1)$ 當切線斜率。

✅ 正確課綱觀念：必須先假設切點為 $(t, f(t))$，切線斜率為 $f'(t)$，再利用「切點與外點連線斜率 $= f'(t)$」解出切點 $t$！

❌ 錯題盲點 3：將定積分（有號面積）與幾何面積混為一談

常見誤區：求 $y = x^3 - x$ 與 $x$ 軸在 $[-1, 1]$ 所圍的「面積」，直接算 $\int_{-1}^1 (x^3-x)\,dx = 0$。

✅ 正確課綱觀念：在 $x$ 軸下方的定積分為負值！求面積必須加絕對值分段積分：$A = \int_{-1}^0 (x^3-x)\,dx + \int_0^1 (x - x^3)\,dx = \frac{1}{4} + \frac{1}{4} = \mathbf{\frac{1}{2}}$！

✍️

課綱指定範例 1 三次多項式的極值、反曲點與切線

1. 設三次函數 $f(x) = x^3 - 3x^2 - 9x + 5$。試求：
(1) $f(x)$ 的相對極大值與相對極小值。
(2) $f(x)$ 圖形的反曲點坐標，以及以反曲點為切點的切線方程式。

🧠 解題破題思路：令 $f'(x) = 3x^2 - 6x - 9 = 0$ 求極值點；令 $f''(x) = 6x - 6 = 0$ 求反曲點 $x = 1$，反曲點處切線斜率即為 $f'(1)$！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：求一階導數與相對極值

$$f'(x) = 3x^2 - 6x - 9 = 3(x + 1)(x - 3) = 0 \implies x = -1 \text{ 或 } 3$$

• 當 $x = -1$ 時，有相對極大值 $f(-1) = -1 - 3 + 9 + 5 = 10$。

• 當 $x = 3$ 時，有相對極小值 $f(3) = 27 - 27 - 27 + 5 = -22$。

步驟 2：求二階導數、反曲點與反曲點切線

$$f''(x) = 6x - 6 = 0 \implies x = 1, \quad f(1) = 1 - 3 - 9 + 5 = -6$$

故反曲點為 $(1, -6)$（注意 $(1,-6)$ 恰為極大點 $(-1,10)$ 與極小點 $(3,-22)$ 的中點！）。

反曲點切線斜率 $m = f'(1) = -12$，切線為 $y - (-6) = -12(x - 1) \implies 12x + y - 6 = 0$。

答：(1) 極大值 $10$、極小值 $-22$；(2) 反曲點 $(1, -6)$，切線 $12x + y - 6 = 0$。

課綱指定範例 2 兩曲線所圍區域面積與定積分

2. 試求拋物線 $y = x^2 - 2x$ 與直線 $y = x + 4$ 所圍成的封閉區域面積。

🧠 解題破題思路：先解聯立 $x^2 - 2x = x + 4 \implies (x+1)(x-4) = 0$ 找出兩交點 $x = -1, 4$，再對「上減下」進行定積分！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：求兩圖形交點橫坐標

$$x^2 - 2x = x + 4 \implies x^2 - 3x - 4 = 0 \implies (x + 1)(x - 4) = 0 \implies x = -1, \; 4$$

步驟 2：計算定積分求面積

在 $[-1, 4]$ 上直線 $y = x + 4$ 在拋物線上方：

$$A = \int_{-1}^4 [(x + 4) - (x^2 - 2x)]\,dx = \int_{-1}^4 (-x^2 + 3x + 4)\,dx$$

$$= \left[-\frac{1}{3}x^3 + \frac{3}{2}x^2 + 4x\right]_{-1}^4 = \frac{125}{6}$$

（以拋物線面積公式驗算：$\frac{|a|}{6}(\beta - \alpha)^3 = \frac{1}{6}[4 - (-1)]^3 = \frac{125}{6}$！）

答：$\frac{125}{6}$。

課綱指定範例 3 定積分求旋轉體體積與球體體積推導

3. (1) 將曲線 $y = \sqrt{x}$ 與 $x$ 軸、直線 $x = 4$ 在第一象限所圍成的區域繞 $x$ 軸旋轉一圈，求所得旋轉體（拋物面碗）的體積。
(2) 利用切片積分法證明半徑為 $R$ 的球體體積為 $\frac{4}{3}\pi R^3$。

🧠 解題破題思路：繞 $x$ 軸旋轉體體積公式為 $V = \pi\int_a^b [f(x)]^2\,dx$！
🔍 點擊展開完整逐步詳解 ▼

第 (1) 題：

$$V = \pi\int_0^4 (\sqrt{x})^2\,dx = \pi\int_0^4 x\,dx = \pi\left[\frac{1}{2}x^2\right]_0^4 = 8\pi$$

第 (2) 題（課綱標準推導）：

將上半圓 $y = \sqrt{R^2 - x^2} \; (-R \le x \le R)$ 繞 $x$ 軸旋轉一圈即得球體：

$$V_{\text{球}} = \pi\int_{-R}^R \left(\sqrt{R^2 - x^2}\right)^2\,dx = 2\pi\int_0^R (R^2 - x^2)\,dx = 2\pi\left[R^2x - \frac{1}{3}x^3\right]_0^R = \frac{4}{3}\pi R^3$$

答：(1) $8\pi$；(2) 如上證得 $\frac{4}{3}\pi R^3$。
