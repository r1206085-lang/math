三角：廣義角參考角、極坐標、正餘弦定理雙證法與差角公式

嚴格遵循課綱脈絡：由直角三角形邊角關係與極坐標出發，引進「參考角 $\alpha$」與單位圓補角關係；以幾何分割與坐標幾何雙重證明正弦定理與餘弦定理，並由餘弦定理直接導出差角、和角、倍角與半角公式！

📌 課綱備註：cot, sec, csc 置於高三選修數甲/乙 I；不含和差化積、積化和差公式；可使用計算器求三角函數值。

🎯 課綱核心學習目標

  • ✓熟練直角三角形的正弦、餘弦、正切定義與平方關係 $\sin^2\theta+\cos^2\theta=1$、餘角關係。
  • ✓理解廣義角的參考角 $\alpha$（與 $X$ 軸的銳夾角）與單位圓 $(\cos\theta, \sin\theta)$ 補角關係，以及極坐標 $[r, \theta]$ 與直角坐標的變換。
  • ✓掌握正弦定理與餘弦定理的兩種課綱證法（分割直角三角形法 vs. 坐標幾何距離與面積法）及海龍公式。
  • ✓能由單位圓與餘弦定理推導差角公式 $\cos(\theta_2-\theta_1)$，進而演繹和角、二倍角与半角公式並應用於平面與立體三角測量。

1. 生活情境引言：雷達極坐標與課綱「三角 → 坐標 → 向量」雙主軸

不用死背「奇變偶不變」也能秒求廣義角？課綱第 60 頁如何串起整冊《數學 III》？

🧭 情境一：參考角 $\alpha$（與 $X$ 軸銳夾角）＋ 單位圓象限坐標

課綱第 61 頁強調：求廣義角 $\theta$ 的三角比只需兩步：

  • 步驟 1（找參考角 $\alpha$）：看終邊與水平 $X$ 軸夾幾度銳角（如 $\theta = \pm 150^\circ \implies \alpha = 30^\circ$；$\theta = \pm 225^\circ \implies \alpha = 45^\circ$）。
  • 步驟 2（配象限正負）：單位圓上點坐標為 $(x, y) = (\cos\theta, \sin\theta)$、斜率為 $\tan\theta = \frac{y}{x}$，看象限正負號直接加在銳角三角比前面即可！

🔗 情境二：課綱兩大黃金推導主軸

正弦定理與餘弦定理不只是解三角形工具，更是後面坐標與向量的源頭：

  • 面積主軸：長方形面積 $\to$ 三角形面積 $\frac{1}{2}bc\sin A$ 與正弦定理 $\to$ 外積與行列式。
  • 長度主軸：畢氏定理 $\to$ 餘弦定理 $a^2=b^2+c^2-2bc\cos A$ $\to$ 坐標距離公式 $\to$ 差角公式 $\cos(\theta_2-\theta_1)$ 與向量內積！

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
廣義角、極坐標與補角關係 $$\sin^2\theta + \cos^2\theta = 1, \quad \tan\theta = \frac{\sin\theta}{\cos\theta}$$ $$\sin(180^\circ - \theta) = \sin\theta, \quad \cos(180^\circ - \theta) = -\cos\theta$$ $$x = r\cos\theta, \; y = r\sin\theta \quad (r = \sqrt{x^2+y^2} \ge 0, \; 0^\circ \le \theta < 360^\circ)$$ • 餘角關係：$\sin(90^\circ-\theta)=\cos\theta, \; \cos(90^\circ-\theta)=\sin\theta$。
面積公式、正弦定理與海龍公式 $$\triangle ABC = \frac{1}{2}bc\sin A = \frac{1}{2}ac\sin B = \frac{1}{2}ab\sin C$$ $$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$ $$\triangle ABC = \sqrt{s(s-a)(s-b)(s-c)}, \quad s = \frac{a+b+c}{2}$$ • $R$ 為 $\triangle ABC$ 外接圓半徑；邊長比等於對角正弦比 $a:b:c = \sin A:\sin B:\sin C$。
餘弦定理（雙證法） $$a^2 = b^2 + c^2 - 2bc\cos A \iff \cos A = \frac{b^2 + c^2 - a^2}{2bc}$$ • 坐標證法（課綱核心觀念）：設 $A(0,0), B(c,0), C(b\cos A, b\sin A)$，由距離公式得 $a^2 = (b\cos A - c)^2 + (b\sin A)^2 = b^2 + c^2 - 2bc\cos A$。
差角、和角、倍角與半角公式 $$\cos(\theta_2 - \theta_1) = \cos\theta_1\cos\theta_2 + \sin\theta_1\sin\theta_2$$ $$\sin(\alpha \pm \beta) = \sin\alpha\cos\beta \pm \cos\alpha\sin\beta$$ $$\sin 2\theta = 2\sin\theta\cos\theta, \quad \cos 2\theta = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta$$ $$\cos\frac{\theta}{2} = \pm\sqrt{\frac{1+\cos\theta}{2}}, \quad \sin\frac{\theta}{2} = \pm\sqrt{\frac{1-\cos\theta}{2}}$$ • 半角公式正負號由半角 $\frac{\theta}{2}$ 所在的象限決定！

3. 常見易錯觀念提醒（課綱盲點診斷）

掃除觀念盲點後，點擊右側按鈕可進入「高中數學錯題本」查看實戰錯題

📓 進入本年級個人手寫錯題本 (grade11-trig.html) →

❌ 錯題盲點 1：正弦定理解 $SSA$ 漏掉鈍角解 $180^\circ - \theta$

常見誤區：已知 $a=4, b=4\sqrt{3}, \angle A=30^\circ$，求得 $\sin B = \frac{\sqrt{3}}{2}$ 只寫 $\angle B = 60^\circ$。

✅ 正確課綱觀念：因為 $b > a$（大邊對大角 $\angle B > 30^\circ$），故銳角 $60^\circ$ 與鈍角 $120^\circ$ 皆滿足內角和小於 $180^\circ$，共有兩解！

❌ 錯題盲點 2：半角公式忘記先將角度範圍除以 2 判斷象限

常見誤區：已知 $180^\circ < \theta < 270^\circ$，求 $\cos\frac{\theta}{2}$ 時看 $\theta$ 在第三象限或直接取正號。

✅ 正確課綱觀念：因為 $180^\circ < \theta < 270^\circ \implies 90^\circ < \frac{\theta}{2} < 135^\circ$（第二象限），第二象限的 $\cos\frac{\theta}{2} < 0$ 必為負！

❌ 錯題盲點 3：將邊長比誤當成角度比

常見誤區：在 $\triangle ABC$ 中已知 $\angle A:\angle B:\angle C = 1:2:3$，誤寫 $a:b:c = 1:2:3$。

✅ 正確課綱觀念：邊長比等於正弦值比：$a:b:c = \sin 30^\circ : \sin 60^\circ : \sin 90^\circ = 1 : \sqrt{3} : 2$！

課綱指定範例 1 差角公式與半角公式雙途徑求 $\cos 15^\circ$

1. 試分別利用 (1) 差角公式 $\cos(45^\circ - 30^\circ)$ 與 (2) 半角公式 $\cos\frac{30^\circ}{2}$ 求 $\cos 15^\circ$ 之精確值。

🧠 解題破題思路：半角公式算出雙重根號後，可利用《數學 I》配方法或分子分母同乘 $2$ 化簡！
🔍 點擊展開完整逐步詳解 ▼

(1) 由差角公式：

$$\cos 15^\circ = \cos(45^\circ - 30^\circ) = \cos 45^\circ\cos 30^\circ + \sin 45^\circ\sin 30^\circ = \frac{\sqrt{2}}{2}\cdot\frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2}\cdot\frac{1}{2} = \frac{\sqrt{6}+\sqrt{2}}{4}$$

(2) 由半角公式：

$$\cos 15^\circ = \sqrt{\frac{1 + \cos 30^\circ}{2}} = \sqrt{\frac{2 + \sqrt{3}}{4}} = \sqrt{\frac{4 + 2\sqrt{3}}{8}} = \frac{\sqrt{3}+1}{2\sqrt{2}} = \frac{\sqrt{6}+\sqrt{2}}{4}$$

答：$\cos 15^\circ = \frac{\sqrt{6}+\sqrt{2}}{4}$。

課綱指定範例 2 餘弦定理、正弦定理與海龍公式

2. 在 $\triangle ABC$ 中，已知 $a = 5, \; b = 7, \; c = 8$，試求：(1) $\angle B$ 的度數；(2) $\triangle ABC$ 的面積與外接圓半徑 $R$。

🧠 解題破題思路：由餘弦定理求 $\cos B = \frac{5^2+8^2-7^2}{2(5)(8)} = \frac{1}{2} \implies \angle B = 60^\circ$。
🔍 點擊展開完整逐步詳解 ▼

(1) 求 $\angle B$：$\cos B = \frac{25 + 64 - 49}{80} = \frac{40}{80} = \frac{1}{2} \implies \angle B = 60^\circ$。

(2) 求面積與 $R$：面積 $= \frac{1}{2}(5)(8)\sin 60^\circ = 10\sqrt{3}$（或由海龍公式 $s=10 \implies \sqrt{10\cdot 5\cdot 3\cdot 2}=10\sqrt{3}$）；由 $2R = \frac{b}{\sin B} = \frac{7}{\frac{\sqrt{3}}{2}} \implies R = \frac{7\sqrt{3}}{3}$。

答：(1) $60^\circ$；(2) 面積 $10\sqrt{3}$，外接圓半徑 $R = \frac{7\sqrt{3}}{3}$。

課綱核心範例 3 立體三角測量（仰角與方位角）

3. 某人在塔的正南方 $A$ 點測得塔頂仰角為 $45^\circ$，接著向東走 $60$ 公尺到達 $B$ 點，測得塔頂仰角為 $30^\circ$。設地面為水平面，求此塔的高度 $h$。

🧠 解題破題思路：設塔底為 $O$、塔頂為 $T$，高度為 $h$，則在直角 $\triangle TOA, \triangle TOB$ 中，$\overline{OA} = h\cot 45^\circ = h$，$\overline{OB} = \sqrt{3}h$，且地面上 $\angle OAB = 90^\circ$（正南與正東垂直）！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：以塔高 $h$ 表示地面距離 $\overline{OA}, \overline{OB}$

• 在 $\triangle TOA$ 中，$\angle TAO = 45^\circ \implies \overline{OA} = h$。

• 在 $\triangle TOB$ 中，$\angle TBO = 30^\circ \implies \overline{OB} = \frac{h}{\tan 30^\circ} = \sqrt{3}h$。

步驟 2：在水平面直角 $\triangle OAB$（$\angle OAB = 90^\circ$）用畢氏定理

$$\overline{OA}^2 + \overline{AB}^2 = \overline{OB}^2 \implies h^2 + 60^2 = (\sqrt{3}h)^2 = 3h^2$$

$$2h^2 = 3600 \implies h^2 = 1800 \implies h = 30\sqrt{2}$$

答：塔高為 $30\sqrt{2}$ 公尺。
