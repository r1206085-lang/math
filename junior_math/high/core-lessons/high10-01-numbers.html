高中核心單元 01 / 18 • 數學 I • 一、數與式 (1.1 ~ 2.2)

數與式：有理數循環小數、雙重根式、算幾不等式與絕對值幾何

建構實數直尺！從有理數的十進位循環小數表示法出發，掌握雙重根號化簡、算幾不等式求極值，以及數線上分點公式與含絕對值的不等式幾何意義。

📌 課綱備註：不含非十進位表示法；不含雙十字交乘法與 x³+y³+z³-3xyz 公式。

🎯 課綱核心學習目標

  • ✓理解實數為有理數的充要條件為其十進位表示法是有限小數或循環小數，並能將循環小數化為分數。
  • ✓熟練乘法公式（立方和、立方差）、繁分式與雙重根式 $\sqrt{(a+b) \pm 2\sqrt{ab}} = \sqrt{a} \pm \sqrt{b}$ 的化簡。
  • ✓掌握正數的算幾不等式 $\frac{a+b}{2} \ge \sqrt{ab}$ 及其等號成立條件（$a = b$），解決幾何與生活極值問題。
  • ✓運用數線上的內分點公式與距離概念 $|x - a|$，解含絕對值的一次方程式與不等式（如 $|x-1| < |2x-3|$）。

1. 生活情境引言：十等分放大鏡與數線拔河比賽

無理數 $\sqrt{2}$ 怎麼在數線上點出來？分點公式為什麼「交叉相乘」？

🔍 情境一：十進位無限放大鏡（實數逼近直觀）

課綱強調：透過不斷將數線作十等分細分，任何實數都能用有限小數夾擠逼近：

  • 有理數的密碼：只要是分數 $\frac{q}{p}$，長除法餘數只有 $0 \sim p-1$ 共 $p$ 種可能，除不盡時必在 $p$ 步內重複，故必為有限小數或循環小數！
  • 雙重根號拆解：看到 $\sqrt{5 + 2\sqrt{6}}$，只要找兩數「相加為 $5$、相乘為 $6$」（即 $3$ 與 $2$），立刻配成 $\sqrt{(\sqrt{3}+\sqrt{2})^2} = \sqrt{3} + \sqrt{2}$！

⚖️ 情境二：分點公式就是「槓桿翹翹板重心」

設點 $P(x)$ 介於 $A(a), B(b)$ 之間，且距離比 $\overline{AP} : \overline{PB} = m : n$：

  • 離誰越近，誰的權重就越大！因此 $a$ 要乘對面的 $n$、$b$ 要乘對面的 $m$：$$x = \frac{na + mb}{m + n}$$
  • 絕對值即距離：$|x - 3| < 2$ 代表「數線上到 $3$ 的距離小於 $2$ 的所有點」，不用代數硬拆，畫數線往左右各走 $2$ 格立刻看出 $1 < x < 5$！

2. 課綱核心公式與推導總整理

嚴格對齊教育部普通高級中學必修與選修數學課程綱要

核心主題 數學公式與定理表徵 課綱推導精神與使用時機
循環小數化分數 $$0.\overline{a_1a_2\cdots a_n} = \frac{a_1a_2\cdots a_n}{\underbrace{99\cdots 9}_{n\text{個}}}, \quad 0.b_1\overline{a_1a_2} = \frac{b_1a_1a_2 - b_1}{990}$$ • 口訣：小數點後「幾位循環寫幾個 $9$，幾位不循環補幾個 $0$」，分子為「全部數字減去不循環部分」。
立方乘法公式與雙重根式 $$(a \pm b)^3 = a^3 \pm 3a^2b + 3ab^2 \pm b^3$$ $$a^3 \pm b^3 = (a \pm b)(a^2 \mp ab + b^2)$$ $$\sqrt{a+b \pm 2\sqrt{ab}} = \sqrt{a} \pm \sqrt{b} \quad (a \ge b > 0)$$ • 雙重根號根號內必須先湊出「$2$ 倍根號」（若為 $\sqrt{4+\sqrt{12}}$ 須先化為 $\sqrt{4+2\sqrt{3}} = \sqrt{3}+1$）。
算幾不等式（AM-GM） 設 $a > 0, \; b > 0$，則：$$\frac{a + b}{2} \ge \sqrt{ab}$$ 等號成立充要條件為 $a = b$ • 幾何證明：以 $a+b$ 為直徑畫半圓，交界處垂直弦長之半為 $\sqrt{ab}$，半徑為 $\frac{a+b}{2}$，半徑必大於等於半弦長！
分點公式與絕對值不等式 • 內分點（$\overline{AP}:\overline{PB}=m:n$）：$x = \frac{na+mb}{m+n}$
• 三角不等式：$|a + b| \le |a| + |b|$（等號成立 $\iff ab \ge 0$）		 • 解 $|x - 1| < |2x - 3|$ 可利用兩邊平方 $(x-1)^2 < (2x-3)^2 \iff (3x-4)(-x+2) < 0$ 或分段討論。

❌ 錯題盲點 1：雙重根式開根號忘記大減小（非負性）

常見誤區：將 $\sqrt{5 - 2\sqrt{6}}$ 寫成 $\sqrt{2} - \sqrt{3} < 0$。

✅ 正確課綱觀念：根號 $\sqrt{\phantom{x}}$ 出來的值必為非負數！因 $\sqrt{3} > \sqrt{2}$，必須寫成 $|\sqrt{2} - \sqrt{3}| = \mathbf{\sqrt{3} - \sqrt{2}}$。

❌ 錯題盲點 2：算幾不等式忽略「正數條件」或「等號無法成立」

常見誤區：求 $x + \frac{4}{x}$ 的最小值直接寫 $2\sqrt{4} = 4$（未確認 $x > 0$）。

✅ 正確課綱觀念：使用算幾不等式前必須確認每一項皆為正數，且必須檢驗 $a = b$ 在題目限制範圍內是否有實數解！

❌ 錯題盲點 3：循環小數 $0.\overline{9}$ 以為小於 $1$

常見誤區：誤以為 $0.999\cdots$ 與 $1$ 差一點點。

✅ 正確課綱觀念：設 $x = 0.\overline{9}$，則 $10x = 9.\overline{9} \implies 9x = 9 \implies x = 1$，故 $0.\overline{9} = 1$ 完全相等！

❌ 錯題盲點 4：分點公式把比例 $m:n$ 直接乘在同側座標

常見誤區：求 $A(1), B(6)$ 之間滿足 $\overline{AP}:\overline{PB}=2:3$ 的點寫成 $\frac{2(1)+3(6)}{5}$。

✅ 正確課綱觀念：分點公式必須交叉相乘：$x = \frac{3(1) + 2(6)}{2 + 3} = \frac{15}{5} = 3$！

4 & 5. 課綱經典範例與點擊展開逐步詳解

課綱指定範例 1 根式化簡與雙重根號運算

1. 試化簡下列各式：
(1) $\frac{1}{\sqrt{2}-1} - \sqrt{5 + 2\sqrt{6}}$
(2) 設 $x > 1$，化簡 $\sqrt{x^2 + x^{-2} + 2} - \sqrt{x^2 + x^{-2} - 2}$。

🧠 解題破題思路：(1) 第一項有理化分母，第二項找兩數和為 $5$、積為 $6$（即 $3, 2$）。(2) 觀察完全平方公式 $(x \pm x^{-1})^2 = x^2 + x^{-2} \pm 2$，開根號時務必加絕對值並利用 $x > 1 \implies x > x^{-1}$ 去絕對值！
🔍 點擊展開完整逐步詳解 ▼

第 (1) 小題：分母有理化與雙重根號拆解

$$\frac{1}{\sqrt{2}-1} = \sqrt{2} + 1, \quad \sqrt{5 + 2\sqrt{6}} = \sqrt{(\sqrt{3}+\sqrt{2})^2} = \sqrt{3} + \sqrt{2}$$

$$\text{原式} = (\sqrt{2} + 1) - (\sqrt{3} + \sqrt{2}) = 1 - \sqrt{3}$$

第 (2) 小題：完全平方配方法與絕對值判讀

$$\text{原式} = \sqrt{(x + x^{-1})^2} - \sqrt{(x - x^{-1})^2} = |x + x^{-1}| - |x - x^{-1}|$$

因為 $x > 1 > 0$，所以 $x + x^{-1} > 0$ 且 $x > \frac{1}{x} \implies x - x^{-1} > 0$：

$$\text{原式} = (x + x^{-1}) - (x - x^{-1}) = 2x^{-1} = \frac{2}{x}$$

答：(1) $1 - \sqrt{3}$；(2) $\frac{2}{x}$。

課綱指定範例 2 算幾不等式求極值與等號成立條件

2. 欲用長 $40$ 公尺的繩子圍出一個長方形花圃（四周皆用繩子），試問長、寬各為多少公尺時，所圍出的長方形面積最大？最大面積為何？

🧠 解題破題思路：設長為 $x$、寬為 $y$，周長 $2(x+y) = 40 \implies x + y = 20$（定和），求面積 $xy$（最大積）立刻使用算幾不等式！
🔍 點擊展開完整逐步詳解 ▼

步驟 1：列出長寬關係與算幾不等式

設長為 $x$ 公尺、寬為 $y$ 公尺（$x, y > 0$），則 $2(x + y) = 40 \implies x + y = 20$。

由算幾不等式：

$$\frac{x + y}{2} \ge \sqrt{xy} \implies \frac{20}{2} \ge \sqrt{xy} \implies 10 \ge \sqrt{xy} \implies xy \le 100$$

步驟 2：求等號成立時的長與寬

當且僅當 $x = y = 10$ 時等號成立，此時面積有最大值 $100$ 平方公尺。

答：長、寬皆為 $10$ 公尺（正方形）時，有最大面積 $100$ 平方公尺。

課綱指定範例 3 含絕對值的不等式與聯立區間

3. 試求下列各不等式的解：
(1) $|x - 3| < 2$ 且 $|x - 1| < 1$ 的解。
(2) $|x - 1| < |2x - 3|$ 的解。

🧠 解題破題思路：(1) 分別解開兩個絕對值區間再取交集。(2) 兩邊皆為非負數，直接「兩邊平方」移項用平方差公式 $(A^2 - B^2) = (A-B)(A+B) < 0$ 最快最不容易錯！
🔍 點擊展開完整逐步詳解 ▼

第 (1) 小題：

• $|x - 3| < 2 \iff -2 < x - 3 < 2 \iff 1 < x < 5$。

• $|x - 1| < 1 \iff -1 < x - 1 < 1 \iff 0 < x < 2$。

• 取兩者交集得：$1 < x < 2$。

第 (2) 小題：兩邊平方用平方差因式分解

$$|x - 1| < |2x - 3| \iff (x - 1)^2 < (2x - 3)^2$$

$$(2x - 3)^2 - (x - 1)^2 > 0 \implies [(2x - 3) - (x - 1)][(2x - 3) + (x - 1)] > 0$$

$$(x - 2)(3x - 4) > 0 \implies x > 2 \text{ 或 } x < \frac{4}{3}$$

答：(1) $1 < x < 2$；(2) $x > 2 \text{ 或 } x < \frac{4}{3}$。
