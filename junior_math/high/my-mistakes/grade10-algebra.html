⚠️ 本單元常見錯誤觀念與避坑指南

❌ 算幾不等式忘記驗證「等號成立條件」或直接拆掉常數

常見誤區：只記得 $\frac{a+b}{2}\ge\sqrt{ab}$，沒配出相乘可消去的未知數（如 $2x+\frac{32}{x+1}$ 沒補 $+2$），或等號條件超出題目範圍。

✅ 正確觀念：先觀察分母，把分子硬湊出「$(x+1)$ 的倍數」，等號成立時令兩項相等，解完務必檢查 $x$ 是否在定義域內。

❌ 絕對值方程式「未檢查右側正負號」就直接平方或去絕對值

常見誤區：看到 $2(x-\sqrt{3})=|x+1|$ 就跟 $2|x-\sqrt{3}|=|x+1|$ 一樣取 $\pm$ 兩個解，忘記左側沒有絕對值時必須 $\ge 0$。

✅ 正確觀念：解出候選根後一定要代回原式驗算！只要有一邊沒有絕對值，就必須先寫出「該邊 $\ge 0$」的限制條件。

第一冊 第 17 題（幾何相似 × 算幾不等式） 🎯 直角三角形截線相似比與乘積最大值
標準答案：$36$
直角三角形 $ABC$ 中，$\overline{AB}=5, \overline{AC}=12, \overline{BC}=13$。直線 $L$ 垂直 $\overline{BC}$，且分別交 $\overline{BC}, \overline{AC}, \overline{AB}$ 的延長線於 $P, Q, R$。求 $\overline{QP} \times \overline{QR}$ 的最大值。
📐 幾何示意圖：直角 $\triangle ABC$ 與垂線 $L$ 截出相似三角形

由相似關係得 $\overline{QP} = \frac{5}{13}a$、$\overline{QR} = \frac{13}{5}b$，相乘剛好消掉係數為 $ab$，再用算幾不等式！

💡 破題關鍵 ＆ 易錯盲點診斷

👍 核心技巧：設 $\overline{CQ}=a, \overline{QA}=b$（故 $a+b=12$），利用母子相似 $\triangle CQP \sim \triangle CBA$ 與 $\triangle RQA \sim \triangle QPC$，把 $\overline{QP}=\frac{5}{13}a$ 與 $\overline{QR}=\frac{13}{5}b$ 相乘，係數 $\frac{5}{13}$ 與 $\frac{13}{5}$ 剛好對消成 $ab$！

🔍 點擊展開完整逐步訂正詳解（含完整推導與觀念對照） ▼

步驟 1（相似比表示 $\overline{QP}, \overline{QR}$）：

設 $\overline{CQ}=a, \overline{QA}=b$，則 $a+b=12$。在直角 $\triangle CQP$ 中 $\overline{QP} = a\tan\theta = \frac{5}{12}?$ 不！$∠ C = \theta$ 時 $\sin\theta = \frac{5}{13}, \cos\theta = \frac{12}{13}$，因 $\angle CPQ = 90^\circ$，故 $\overline{QP} = a\sin\theta = \frac{5}{13}a$；又 $\angle AQR = 90^\circ - \theta$ 嗎？因 $L\perp BC$，在 $\triangle AQR$ 中 $\angle ARQ = \theta$，故 $\overline{QR} = \frac{b}{\sin\theta} = \frac{13}{5}b$。

步驟 2（算幾不等式求最大值）：

$$\overline{QP} \times \overline{QR} = \left(\frac{5}{13}a\right)\left(\frac{13}{5}b\right) = ab \le \left(\frac{a+b}{2}\right)^2 = \left(\frac{12}{2}\right)^2 = 36$$
第一冊 根式化簡 ③（無理數合併條件） 🎯 兩邊平方後正整數因數分解求數對 $(x, y)$
標準答案：$(x, y) = (5, 245)$ 或 $(7, 175)$
設 $x, y$ 為正整數且 $x < y$，若 $\sqrt{x}, \sqrt{y}$ 為無理數，且 $\sqrt{x} + \sqrt{y} = \sqrt{x+y+70}$，求數對 $(x, y)$。
💡 破題關鍵 ＆ 易錯盲點診斷

⚠️ 關鍵盲點：原本寫了 $(35, 35)$ 但漏看「$x < y$」的限制！平方得到 $2\sqrt{xy}=70 \implies xy = 35^2 = 5^2 \times 7^2$，將 $5^2 \cdot 7^2$ 拆成相異兩數且兩者都不能是完全平方數（否則 $\sqrt{x}$ 會變有理數，例如 $(1, 1225)$ 或 $(25, 49)$ 不合），就只剩 $(5, 245)$ 與 $(7, 175)$！

🔍 點擊展開完整逐步訂正詳解（含完整推導與觀念對照） ▼

步驟 1（兩邊平方消去 $x+y$）：

$$x + y + 2\sqrt{xy} = x + y + 70 \implies \sqrt{xy} = 35 \implies xy = 35^2 = 5^2 \times 7^2$$

步驟 2（扣除完全平方數與 $x \ge y$）：

因 $x < y$ 且 $\sqrt{x}, \sqrt{y}$ 皆為無理數（排除 $1, 25, 49$），僅剩 $(x, y) = (5, 245)$ 與 $(7, 175)$。

第一冊 範例 3（實數不等式符號判別） 🎯 代數字反證法判斷 $a, b, p, q$ 正負號
標準答案：(A)(C)
設 $a, b, p, q$ 為實數，已知 $a > b$，且 $ap, aq, bp, bq$ 四個相異數之中，以 $ap$ 為最大，$aq$ 為最小，則下列哪些數值必為正數？（多選）
(A) $a$ (B) $b$ (C) $p$ (D) $q$ (E) 條件不足無法判定
💡 破題關鍵 ＆ 易錯盲點診斷

👍 極佳解法：可用具體數字測試正負號，快速驗證不等式方向！由 $a > b$ 且 $ap > bp \implies (a-b)p > 0 \implies p > 0$；由 $bq > aq \implies (a-b)q < 0 \implies q < 0$；再由 $ap > aq$（不！要看 $ap$ 最大且 $aq$ 最小，若 $a < 0$，則 $a q > 0 > a p$ 就矛盾了，所以必有 $a > 0$！）。

🔍 點擊展開完整逐步訂正詳解（含完整推導與觀念對照） ▼

1. $ap > bp \implies (a-b)p > 0$，因 $a > b$ 故 $p > 0$。

2. $bq > aq \implies (a-b)q < 0 \implies$ $q < 0$。

3. 因 $p > 0 > q$ 且 $ap > aq$，故 $a(p-q) > 0$ 恆成立；但因 $ap$ 最大且 $aq$ 最小，若 $a \le 0$ 則 $ap \le 0 \le aq$ 矛盾，故必有 $a > 0$（而 $b$ 可正可負，如 $a=5, b=-3$）。選 (A)(C)。

第一冊 閱讀素養題（最大乘積＋對數估位數） 🎯 整數拆解乘積最大化（儘量拆 3）＋ $\log$ 估算位數與最高位
標準答案：$17$ 位數、最高位數字 $7$、個位數字 $4$
將正整數 $100$ 分解成若干個正整數相加（儘量分解成 $3$ 相加，若剩 $2$ 留著，剩 $1$ 則與一個 $3$ 合成 $4$），其乘積的最大數值為多少位數？最高位數字與個位數字分別為何？
💡 破題關鍵 ＆ 易錯盲點診斷

👍 做得好：$100 = 3 \times 32 + 4$，最大乘積為 $3^{32} \times 4$。利用 $\log(3^{32}\times 4) = 32(0.4771) + 2(0.3010) = 15.8692$，小數部分 $0.8692$ 介於 $\log 7 \approx 0.8451$ 與 $\log 8 \approx 0.9030$ 之間，所以首位是 $7$！個位數靠 $3^k$ 的 $4$ 循環週期算得 $3^{32}$ 尾數為 $1$，乘 $4$ 得 $4$。

🔍 點擊展開完整逐步訂正詳解（含完整推導與觀念對照） ▼

步驟 1（最大乘積式）：$100 = 3 \times 32 + 4$，最大乘積 $M = 3^{32} \times 4$。

步驟 2（位數與最高位數字）：

$$\log M = 32\log 3 + 2\log 2 \approx 32(0.4771) + 2(0.3010) = 15.2672 + 0.6020 = 15.8692$$

首數 $15 \implies 15 + 1 = 16$ 位數？注意核對：$32(0.47712) = 15.2679$，$+0.60206 = 15.8700$，首數是 $15$，故位數為 $16$ 位數（計算位數時記得「位數 $=$ 首數 $+1$」，避免多加 $1$！$10^{15.87} = 10^{0.87}\times 10^{15}$，後面有 $15$ 個 $0$ 總共 $16$ 位數！）；又 $\log 7 \approx 0.8451 < 0.8692 < \log 8 \approx 0.9031$，故最高位數字為 $7$。

步驟 3（個位數字）：$3^n$ 個位數以 $3, 9, 7, 1$ 四個一循環，$32 \equiv 0 \pmod 4$ 故 $3^{32}$ 個位為 $1$，$1\times 4 = 4$。

第一冊 算幾配湊題（分式函數矩形周長最小值） 🎯 補常數使乘積消元後套用算幾不等式
標準答案：在 $x = 3$ 時有最小周長 $14$
函數 $f(x) = \frac{16}{x+1}$（$x \neq -1$）圖形上有一點 $P$（在第一象限），$P$ 投影到 $x$ 軸為 $A$、投影到 $y$ 軸為 $B$，則 $P, A, B$ 與原點連成的長方形周長在 $x = \underline{\quad}$ 時有最小值 $\underline{\quad}$。
📐 函數圖形：$y = \frac{16}{x+1}$ 第一象限矩形投影示意圖

配湊成 $(2x+2) + \frac{32}{x+1} - 2$ 後使用算幾不等式，得最小周長 $14$（在 $x=3$ 成立）。

💡 破題關鍵 ＆ 易錯盲點診斷

⚠️ 關鍵盲點：周長是 $2x + \frac{32}{x+1}$，為讓 $(2x+\text{常數})$ 能跟分母 $(x+1)$ 消掉，必須把 $2x$ 寫成 $(2x+2) - 2$！先對 $(2x+2) + \frac{32}{x+1} \ge 16$ 做算幾，最後一定要記得扣回那個 $2$ 變成 $14$！

🔍 點擊展開完整逐步訂正詳解（含完整推導與觀念對照） ▼

步驟 1（配湊周長式）：

$$\text{周長} = 2\left(x + \frac{16}{x+1}\right) = (2x + 2) + \frac{32}{x+1} - 2$$

步驟 2（算幾不等式）：因 $P$ 在第一象限（$x > 0$）：

$$(2x + 2) + \frac{32}{x+1} \ge 2\sqrt{(2x+2)\cdot\frac{32}{x+1}} = 2\sqrt{64} = 16$$

故周長最小值為 $16 - 2 = 14$。等號成立於 $2(x+1) = \frac{32}{x+1} \implies (x+1)^2 = 16 \implies x = 3$。

第一冊 索菲熱爾曼恆等式（$n^4 + \frac{1}{4}$ 分解與連乘對消） 🎯 補項配平方差因式分解 $\to$ 連乘約分
標準答案：① $(n^2+n+\frac{1}{2})(n^2-n+\frac{1}{2})$；② $20201$
① 因式分解 $n^4 + \frac{1}{4}$。
② 化簡 $\frac{\left(2^4+\frac{1}{4}\right)\left(4^4+\frac{1}{4}\right)\cdots\left(100^4+\frac{1}{4}\right)}{\left(1^4+\frac{1}{4}\right)\left(3^4+\frac{1}{4}\right)\cdots\left(99^4+\frac{1}{4}\right)}$。
💡 破題關鍵 ＆ 易錯盲點診斷

👍 超漂亮：利用 $n^4 + \frac{1}{4} = (n^2 + \frac{1}{2})^2 - n^2$ 拆成 $(n^2-n+\frac{1}{2})(n^2+n+\frac{1}{2})$，再令 $f(n) = n^2 - n + \frac{1}{2}$，則第二個括號恰好是 $f(n+1)$！因此分子分母從 $f(2)\sim f(100)$ 全部約光，只剩 $\frac{f(101)}{f(1)} = \frac{100^2+100+0.5}{0.5} = 20201$！

🔍 點擊展開完整逐步訂正詳解（含完整推導與觀念對照） ▼

① 因式分解：

$$n^4 + \frac{1}{4} = \left(n^2 + \frac{1}{2}\right)^2 - n^2 = \left(n^2 + n + \frac{1}{2}\right)\left(n^2 - n + \frac{1}{2}\right)$$

② 連乘對消：設 $g(n) = n^2 - n + \frac{1}{2}$，則 $n^2 + n + \frac{1}{2} = g(n+1)$，故 $n^4+\frac{1}{4} = g(n)g(n+1)$。

$$\text{原式} = \frac{[g(2)g(3)][g(4)g(5)]\cdots[g(100)g(101)]}{[g(1)g(2)][g(3)g(4)]\cdots[g(99)g(100)]} = \frac{g(101)}{g(1)} = \frac{100^2 + 100 + \frac{1}{2}}{1^2 - 1 + \frac{1}{2}} = \frac{10100.5}{0.5} = 20201$$
第一冊 第 2 題（含絕對值集合相等判別） 🎯 解絕對值方程式與檢查非負限制條件
標準答案：(1) $A = B \neq C$
設集合 $A = \{x \in \mathbb{R} \mid 2|x-\sqrt{3}| = |x+1|\}$、$B = \{x \in \mathbb{R} \mid 2|x-\sqrt{3}| = x+1\}$、$C = \{x \in \mathbb{R} \mid 2(x-\sqrt{3}) = |x+1|\}$，試問下列哪一個選項正確？
(1) $A=B\neq C$ (2) $B=C\neq A$ (3) $C=A\neq B$ (4) $A=B=C$ (5) $A\neq B$ 且 $B\neq C$
💡 破題關鍵 ＆ 易錯盲點診斷

⚠️ 關鍵盲點：算出兩個候選根 $2\sqrt{3}+1$ 與 $\frac{2\sqrt{3}-1}{3} \approx 0.82$ 後，套進條件檢查：
• $B$ 要求 $x+1 \ge 0$（兩個都大於 $-1$，全過 $\implies B=A$）。
• $C$ 要求 $x-\sqrt{3} \ge 0$（$0.82 < 1.732$ 不合，少一個根 $\implies C \neq A$）。

🔍 點擊展開完整逐步訂正詳解（含完整推導與觀念對照） ▼

步驟 1（解 $A$）：$2(x-\sqrt{3}) = \pm(x+1) \implies x_1 = 2\sqrt{3}+1 \approx 4.464$ 或 $x_2 = \frac{2\sqrt{3}-1}{3} \approx 0.821$。

步驟 2（檢查 $B, C$ 條件）：

• $B$ 需 $x+1 \ge 0$（$x \ge -1$）：$x_1, x_2$ 皆滿足，故 $B = A$。

• $C$ 需 $x-\sqrt{3} \ge 0$（$x \ge 1.732$）：僅 $x_1$ 滿足，$x_2$ 不合，故 $C \subsetneq A$。選 (1)。

第一冊 第 7 題（二元線性不等式極值與面積） 🎯 線性組合（拆成已知變數）取代個別極值相加
標準答案：(1)(2)(4)
設 $x, y$ 均為實數，且滿足 $|x-1| \le 2$ 且 $|x+y| \le 1$，請選出正確的選項。（多選）
(1) $-1 \le x \le 3$
(2) $-4 \le y \le 2$
(3) $5 \le x^2+y^2 \le 25$
(4) $x - 2y \ge -6$
(5) 滿足題意的 $(x, y)$ 在坐標平面上形成的圖形面積為 $24$
📐 區域面積示意圖：$|x-1|\le 2$ 與 $|x+y|\le 1$ 圍成平行四邊形

兩垂直線距為 $3 - (-1) = 4$（高），鉛直邊長為 $1 - (-1) = 2$（底），平行四邊形面積 $= 2 \times 4 = 8$。

💡 破題關鍵 ＆ 易錯盲點診斷

⚠️ 關鍵盲點：求 $x-2y$ 的範圍時，千萬不能分別用 $x$ 的範圍與 $y$ 的範圍直接相減（會過度放大誤差）！要把目標式線性組合成已知的 $(x)$ 與 $(x+y)$：$x - 2y = 3x - 2(x+y)$，就能精確得出範圍 $[-5, 11]$！

🔍 點擊展開完整逐步訂正詳解（含完整推導與觀念對照） ▼

(1) ✅ 正確：$|x-1|\le 2 \iff -1 \le x \le 3$。

(2) ✅ 正確：$y = (x+y) - x$，因 $-1 \le x+y \le 1$ 與 $-3 \le -x \le 1$，相加得 $-4 \le y \le 2$（皆可在頂點取到）。

(3) ❌ 錯：$(0,0)$ 滿足條件，故 $x^2+y^2$ 最小值為 $0$（非 $5$）。

(4) ✅ 正確：寫成 $x - 2y = 3x - 2(x+y)$，由 $-3 \le 3x \le 9$ 與 $-2 \le -2(x+y) \le 2$ 相加得 $-5 \le x-2y \le 11$，恆有 $x-2y \ge -5 \ge -6$。

(5) ❌ 錯：平行四邊形底 $2$、高 $4$，面積 $= 8$。選 (1)(2)(4)。

第一冊 指數 × 算幾不等式（動點在直線上的極值） 🎯 把 $8^x + 4^y$ 化為同底 $2^{3x} + 2^{2y}$ 套用算幾不等式
標準答案：(3) 沒有最大值，但有最小值 $8\sqrt{2}$
當 $P(x, y)$ 在直線 $3x + 2y = 5$ 上變動時，關於 $Q = 8^x + 4^y$ 的敘述，下列何者正確？
(1) $Q$ 有最大值 $33$，最小值 $8\sqrt{2}$ (2) $Q$ 有最大值 $12$，但沒有最小值 (3) $Q$ 沒有最大值，但有最小值 $8\sqrt{2}$ (4) $Q$ 沒有最大值，但有最小值 $12$ (5) $Q$ 沒有最大值也沒有最小值
💡 破題關鍵 ＆ 易錯盲點診斷

👍 標準漂亮解法：看到指數相加就先換底數成 $2^{3x} + 2^{2y} > 0$，相乘時指數相加剛好就是題目給的定值 $3x+2y=5$！當 $x\to +\infty$ 時 $y\to -\infty$，$8^x \to +\infty$ 故沒有最大值。

🔍 點擊展開完整逐步訂正詳解（含完整推導與觀念對照） ▼

步驟：因 $2^{3x} > 0, 2^{2y} > 0$，由算幾不等式：

❌ 常見盲點 1：以為「等差數列」與「等比數列」互斥

常見誤區：看到等比數列就直覺排除等差數列的可能。

✅ 正確觀念：當非零常數數列 $x = y = z \neq 0$ 時，它是公差 $d = 0$ 的等差數列，同時也是公比 $r = 1$ 的等比數列！

❌ 常見盲點 2：等比數列取對數後一般項常數項算錯

常見誤區：由 $a_n = 3 \cdot (3\sqrt{3})^{n-1} = 3^{\frac{3}{2}n - \frac{1}{2}}$ 寫成 $\log_3 a_n = \frac{3}{2}n - 1$。

第 1 題（多選題） 🎯 連等式參數化 $k$ 與等差／等比數列判別
標準答案：(3)(4)
已知 $x, y, z$ 皆為異於 $1$ 的正數，且 $x^{\frac{1}{5}} = \left(\frac{y}{2}\right)^{\frac{1}{6}} = \left(\frac{z}{4}\right)^{\frac{1}{7}}$。試選出正確的選項。
(1) $x > y > z$
(2) $x < y < z$
(3) $x, y, z$ 可能形成等差數列
(4) $x, y, z$ 可能形成等比數列

步驟 1：參數化表示 $x, y, z$

$$\frac{y}{x} = \frac{2k^6}{k^5} = 2k, \quad \frac{z}{y} = \frac{4k^7}{2k^6} = 2k$$

因為 $\frac{y}{x} = \frac{z}{y} = 2k$ 恆成立，所以不論 $k$ 為何值，$x, y, z$ 必定形成公比為 $2k$ 的等比數列！故 (4) 正確、(5) 錯誤。

❌ 常見盲點 1：解出三角形邊長比例後，忘記檢查「三角形兩邊和大於第三邊」

常見誤區：解二次方程式得 $a = \frac{4}{3}c$ 或 $a = \frac{1}{4}c$ 兩解不知如何取捨。

❌ 常見盲點 2：使用正弦定理忘記 $\frac{a}{\sin A} = 2R$（外接圓直徑）

✅ 正確觀念：只要題目給出圓的直徑 $2R$，任一弦長 $\overline{CE}$ 與對角 $A$ 立刻滿足 $\frac{\overline{CE}}{\sin A} = 2R = \overline{AB} \implies \frac{\overline{CE}}{\overline{AB}} = \sin A$！

❌ 錯題盲點 1：把對數相加誤當成真數相加
